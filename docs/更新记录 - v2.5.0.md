# v2.5.0 更新记录 ——「长记忆」

## 新增

- **记忆管理页**（导航栏新增「记忆」）：浏览每个聊天的近期对话 / 重要记忆 / 关键词索引 / 深层存档四类记忆；支持删除整个聊天记忆（确认框 + 输入聊天名二次确认）与逐条删除；深层存档懒加载（每页 200 条）+ 内容搜索。界面为三个固定比例框 + 框内滚动布局，全部主题自适应
- **长记忆三层**：
  - **深层记忆**：近期窗口溢出的消息自动归档进 `memory_deep/`（永不删除）；模型在记不清时经 `recall_memory` 工具检索全量历史——「我之前说过什么」不再靠猜
  - **重要记忆**（可选）：压缩模型每攒满一批历史自动提炼必须长期记住的信息（身份、偏好、承诺、重大事件），常驻上下文，上限防膨胀
  - **关键词索引**（可选）：压缩模型同步为历史话题配置检索关键词，用户消息命中时相关记忆自动注入上下文
  - 设置页新增「长记忆」配置区：深层/压缩开关、近期保留条数、每批压缩条数、重要记忆上限、压缩模型下拉（留空随聊天模型），保存即时生效
- **联网搜索换措辞重试**：搜索结果与查询主题明显无关时，模型自动调整词序、增删限定词重搜

## 优化

- **联网搜索三源并发**：百度 + 搜狗 + 必应并发请求、按优先级合并去重。根治中文人名/机构查询失准——cn.bing 对「福州大学 唐勇」类查询分词失败、返回「唐朝/比亚迪」等无关实体卡（加引号/换市场参数实测均无效），百度/搜狗全部精准命中（探针实测「福州大学 唐勇」第一条即经管学院教师页）；DuckDuckGo 降为三源全空时兜底（国内需代理）
- **输入缓存命中优化**：消息序列改为「稳定前缀在前（人设 → 重要记忆 → 历史）、每轮变化区在尾（相关记忆 → 当前时间紧贴当前消息）」——上一轮完整请求成为下一轮前缀，实机实测第二轮请求缓存命中约 71%（此前「当前时间」插在人设后导致每轮全价），长对话 API 输入费用显著下降
- **纯图/表情消息角色化**：纯图路径并入统一 vision 链路，看图后直接以角色身份回复（此前走旧两段式的「专业图像描述 AI 客观复述」，回复像图片说明而非角色反应）；纯图消息同时接入对话历史
- **上下文预算裁剪保序化**：超长历史裁剪不再把 system 消息搬到最前，缓存友好的消息布局在裁剪后保持稳定

## 移除

- `vision_prompt` / `vision_temp` 配置项与 CLI `vision-temp` 命令（图片复述时代遗留；视觉调用统一随聊天模型、聊天温度与人设）

## 修复

- 设置页构造期属性断裂（删除旧方法时误删同区间在用方法，真机启动才暴露）——新增 UI 页面常驻冒烟测试，此类断裂跑测试即拦截
- 用量统计按天分组在午夜前后运行时跨天错位（时间边界锚定正午加固）

## 升级注意

- 旧 `memory.json` 启动时自动迁移：超出近期窗口（默认 30 条）的历史整体归档进深层存档，不丢数据
- **记忆压缩默认关闭**（每次提炼产生少量 API 用量），深层归档默认开启——需要「重要记忆/关键词索引」请在设置页手动开启
- 深层存档位于 memory.json 同目录的 `memory_deep/` 下；在记忆页删除整个聊天记忆时会一并清理

## 已知边界

- 关键词索引召回受措辞差异限制（同义词/昵称可能漏检）——模型可主动调 `recall_memory` 兜底
- 百度对自动化访问高频触发安全验证页（自动降级为空结果，由搜狗/必应补位）
- 抓取式搜索无 SLA：搜索引擎改版会导致解析失效（三源互为冗余 + 模型换措辞重搜兜底）

## 安装

下载 `xiaoli-setup-v2.5.0.exe` 双击安装（免管理员权限），旧版本可直接覆盖安装，配置、角色卡与记忆自动保留。
