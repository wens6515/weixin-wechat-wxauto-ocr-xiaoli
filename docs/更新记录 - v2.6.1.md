# v2.6.1 更新记录 ——「多图识别」

## 新增

- **多图一次识别**：对方连发多张图片（可带文字）时，全部图片按发送顺序与文字一起放进**同一次视觉调用**——不再只读最新一张：
  - 图+文、纯多图两条路径均生效；模型一次看完所有图再回复，「这几张连起来看」的语境不丢
  - 任务判定时全部图片随任务投递：逐张复制进任务目录 `attachments\`，task.json 的 attachments 清单齐全，天枢按清单读取
  - 新增媒体框阈值过滤（以 bot 最后回复为界）：只捕获对方本轮新图，bot 自己的文件卡片与历史媒体不误入
  - 单张捕获失败（复制为空 / 裁剪越界）自动跳过该张，不拖垮整批

## 优化

- **模型预设刷新**：快捷添加的预设模型更新为各平台现行旗舰——智谱 GLM-5.3 / GLM-5.3-flash、Kimi K3、通义 Qwen3.8-max / flash、豆包 Seed-Evolving / Seed-2.0-mini、硅基流动 DeepSeek-V4 系列，全部带现行价目（估算消费不落空）

## 修复

- 定时触发器到点后日志误报「触发失败 name 'content' is not defined」：发送与确认出队一直正常，纯日志噪音，改为记录实际生成的回复

## 升级注意

- 旧配置不受影响：预设模型只是「快捷添加」按钮的候选清单，已配置的 Provider 与模型原样保留
- 多图捕获每张约 2 秒（点击 → 复制 → 关闭查看器），多图事件端到端耗时会随图数增加，属预期

## 安装

下载 `xiaoli-setup-v2.6.1.exe` 双击安装（免管理员权限），旧版本可直接覆盖安装，配置、角色卡与记忆自动保留。
