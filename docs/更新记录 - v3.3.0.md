# 更新记录 · v3.3.0「引用识别与小漓状态层」

## 引用消息识别与内容联动

此前对方「引用」一条消息发来时，小漓会把引用区的内容物（图片缩略图/文件图标）当成图片消息处理：正文整行丢弃、缩略图被当图裁剪送视觉、还会白等 10 秒防抖——对方引用一张图问「这是什么」，小漓只能瞎猜。本版把引用消息做成完整链路：

- **判型重构**：引用块 = 气泡面板 + 面板下方带左缘竖线的引用区（深/浅双主题真机标定）。判 kind 优先级改为「面板+面板内图标 = 文件 → 有面板 = 文字/引用 → 无面板有媒体框 = 图片」，引用内容物不再被当成本轮图片；
- **内容物专用检测**：引用区竖线条带内 24px 起判的实心块检测（缩略图/文件图标）——通用媒体判据的 40px 闸会漏掉 ~30px 宽的窄缩略图；阈值按主题分档（浅色下白底缩略图与背景只差 15 色阶）；
- **标注注入**：引用内容以 `[引用 王文生：文件名]` / `[引用 王文生发来的图片]` 前缀随正文进模型——此前引用文字从未进过模型（块底沿只画到气泡面板底，引用行全部被丢弃）；
- **引用图片联动**：点击引用区缩略图打开图片查看器，与普通图片同一套「复制原图 → 失败落裁剪」机制捕获后随文字进同一次 vision 调用——模型看得到被引用的那张图；
- **引用文件联动**：按显示名在接收目录定位被引用的文件，走与「文件+指令」完全相同的流程（vision 判任务投递 / 读内容回复）；找不到（如引用的是小漓自己发的文件）自然落回文字处理。

## 小漓状态层（默认关）

让小漓的语气随时段、聊天热度与近期情绪自然起伏——深夜犯困、聊得投入会兴奋、被夸了会开心。三块数据两个来源：

- **时段精力、聊天热度**：本地计算零成本（时钟 + 记忆数据）；
- **情绪与精力损耗**：每次回复完整发出后，后台一次小调用定量（每聊天 5 分钟节流，失败静默保留旧状态，情绪 6 小时新鲜度），落盘 persona_state.json；
- 注入在「当前时间」之后的尾区，不破坏 API 前缀缓存；提示词明确「是背景感受不是台词」，避免每条回复都复读状态；
- 设置页开关（默认关，开启有额外少量 API 成本由用户决定），新增**「状态」页**可视化：当前时段 + 每聊天心情/精力进度条/更新时间。

## 主动追尾（默认关，参数全可设）

像真人那样偶尔回完话想起什么，过一会儿补一条短消息。机制上不依赖模型自觉调工具：回复发出后在用户设置的延迟区间（默认 45~90 秒）内随机取时刻，由系统主动发起一次小评估调用，模型只需二选一（补一句 / 不补），并被要求「十次里最多补两三次」。护栏：每聊天冷却、每日全局上限、仅私聊（均可设）+ 固定护栏「等待期间对方又发消息自动取消」；发送走切会话 + 标题复验，绝不发错人。

## 媒体等待双模式

对方发图片/文件后等一等跟发的文字，防拆散任务描述。此前是固定盲等 10 秒。本版做成两档用户选：

- **固定等待**（默认）：与历史行为一致；
- **智能静默**：纯像素静默期检测——每 2 秒重数一次对方消息块，出现新块（还在连发）就重置计时，连续静默 N 秒（可配，默认 5）即继续，硬上限 12 秒兜底。零 OCR 零 API 成本；对方跟发长任务描述不会拆散，没跟文字时也不白等。

## 每日消费预算（默认关）

按内置价目估算今日消费，达到上限当天不再发起模型调用（红圈仍会清掉、不漏处理），第二天自动恢复；用量页新增今日预算进度条。注意口径是估算不是账单（无价目的模型不计入）。

- DeepSeek：预设改为 **deepseek-flash**（V4.1 Flash 现行名，原生多模态），价目按官方现行价（高峰 2/8、空闲 1/4、缓存命中 0.04/0.02 元每百万）；旧模型名 v4-flash / v4-flash-vision-exp 并行保留且同价；

- 智谱：GLM-5.3-Flash 缓存命中价修正为现行刊例 0.23（原生带视觉能力）；
- 兜底视觉模型名同步更新为 deepseek-flash。

## 界面与体验

- **日志页与记忆页最新在顶**：日志页最新一行永远在第一行（首页运行日志小窗保持原样）；记忆页近期对话与深层存档均为最新在前，深层存档分页从最新一头开始、「加载更多」向更早翻页（编辑/删除的序号仍精确映射存储位次）；
- **小表情识别剔除头像区**：微信自带小表情（❤）的裁剪范围左沿从头像带内移到带外——此前裁剪图里带着用户的头像图片，视觉模型会对着头像内容（如「已无生命体征」梗图）自由发挥而不是看表情本身；
- **回复长度上限默认 40000**：历史默认 400 连推理模型的思考 token 都装不下；长度纪律本来就由回复风格提示词管，这里只是物理兜底（老配置已显式存 400 的需在模型页手动改一次）；
- **语音转文字引导**：首启引导与设置页语音区提示——到电脑版微信「设置 → 通用」开启语音自动转文字，小漓才能读懂对方发来的语音。
