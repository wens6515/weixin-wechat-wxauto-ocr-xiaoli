# 更新记录 v2.2.0（2026-08-29）

> 角色沉浸要求升级为「会话首条消息自动注入」，页面切换动画整体重做（方向感知推挤），默认主题/壁纸换成「深海小漓」套，修复主题选择器对勾错位。原「黑块移动」的切换观感从机制上移除。

## 核心升级

- **角色沉浸要求：首条消息自动注入**——沉浸指令从 system prompt 拆出，改为每个会话（联系人/群）第一条消息后空行注入，随消息写入该会话历史并按【角色沉浸要求】标记去重（一次注入、整个会话生效；新联系人/清空记忆自动重注）。挂载点双路覆盖：`_vision_route`（消息主路，README 流程图节点 I）与 `call_chat_ai`（vision 失败降级路）共用 `_with_immersion`——只挂降级路会导致主路聊天永远收不到指令（实测教训）。角色卡模板回归纯人设正文，旧沉浸块移除。
- **沉浸文案定稿**——「但最终回复必须直接说人话，不要出现用括号包裹内心活动或者动作」，首条消息正文与指令之间空行分隔。
- **页面切换动画整体重做（方向感知整叠推挤）**——导航目标在下方 → 内容整体上推，在上方 → 下拉；新旧两页锁同速平移、边缘严丝合缝，露出的全部是真实渲染内容。前三版（旧页淡出叠新页升起 / 新页快照淡入 / 自上而下擦除）在半透明深色面板 + 壁纸的组合下都会产生「黑块移动/双重曝光」观感（真机截图实证），推挤方案从机制上不存在深色块。动画中再点导航立即定格并切换，快速连点不排队不等待。
- **默认主题/壁纸换「深海小漓」套**——默认主题 `abyss`（深海小漓 · 人设主题）+ 默认壁纸 `小漓主题.jpg`（裸文件名 → 启动时按壁纸库解析绝对路径，兼容源码/打包两种运行形态）；旧出厂默认（blue/tokyonight、壁纸空）自动迁移，用户手动选过的其他主题/壁纸不覆盖。壁纸配套主题（7 套）在设置页排序置顶。

## 修复

- **主题/壁纸选中对勾错位**——`ThumbDelegate._draw_check` 把外接框左上角误当圆心传给 `drawEllipse(QPointF 圆心, …)` 重载，圆整体偏左上与对勾错位，且圆冒出缩略图被裁剪；对勾与圆同心、完整落在缩略图内。
- **测试隔离**——天枢授权测试（TestGrantTasksDirToTianshu）补钉 `RIVET_HOME` 环境变量：本机设了 `RIVET_HOME` 时原测试会读写真实 CLI 配置（既失败又污染真实配置）。

## 打包/工具

- **package_xiaoli.ps1 双模式**——默认「重置测试区」（重打后 dist\小漓 为纯净状态，首启走全新安装），`-KeepRuntime` 保留 config/memory/cards/wxauto 运行时数据。
- 全量单测 290 个通过（新增沉浸注入/去重、vision 主路注入等用例）。

## 已知边界

- 沉浸指令随首条消息参与 vision 单调用的任务判断（首条消息本身是任务时会被投递而非聊天回复，属设计内行为）。
- 已有会话历史中已注入旧版沉浸文案的，按标记去重不会替换为新文案（清空该会话记忆即可）。
- 上下文压缩/世界书、文件追问缓存、定时主动消息、微信窗口自动定位、用量统计规划于后续版本。
