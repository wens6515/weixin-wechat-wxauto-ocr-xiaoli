# 更新记录 v2.1.1

> v2.1.0 发布后的用户实测修复轮：模型配置页 3 个问题 + 角色卡中文名 1 个问题，另调整页面切换动画。

## 核心修复

- **模型配置页 ①：重启后模型选择丢失 → 启动 bot 报 API 400**——「保存并应用」原来只落盘 providers、从不写活跃卡的 `chat_model`，重启后模型下拉为空、bot 启动 model 为空导致 400。现在保存时把当前模型配置写入活跃卡；下拉为空时不覆盖卡上已有模型；卡模型为空时自动回填当前 provider 首个模型。
- **模型配置页 ②：API Key 单元格选中框过窄 + 双击编辑框位置偏移**——移除表格 item 的 padding（行高改由 min-height 撑起），并取消单击即编辑（单击只选中，双击/F2 才编辑），编辑框几何不再错位。
- **模型配置页 ③：模型下拉展开动画卡顿**——禁用系统 AnimateCombo/FadeMenu 动画，精简下拉列表 item 的圆角与 padding，深色大列表展开不再逐帧重绘卡顿。
- **角色卡中文名保存报「校验失败」**——id 生成用 `isalnum()` 对中文误放行（中文返回 True），导致非 ASCII 中文混入 id 被白名单校验拒绝。现过滤加 `isascii()`，中文名走时间戳 fallback id（如 `card_1787466056_66056`），显示名仍保留中文。
- **页面切换动画调整**：多轮调整后定为简单方案（新页升起 + 旧页快照淡出）600ms；若需再调，改 `main_window.py` FadeStackedWidget `duration=600` 一处即可。
- **dist 版启动崩溃修复**：移除 `Qt.UIEffect.UI_FadePopup`——当前 PySide6 无此枚举，dist 版启动即 AttributeError 崩溃。

## 说明

- 全部修复均带回归测试；全量 256 单测绿 + dist 冒烟启动通过。
- 发布前请重新下载安装包；已安装用户覆盖安装即可，无需重新配置（打包基于当前配置兼容）。

## 已知边界

- 动画 600ms 手感、模型配置页视觉效果需用户在重新打包后的 dist 版实测确认。
- 遗留（自 v2.1.0，未处理）：`vision-exp` 模型与 tools 组合的真实 API 探针、图片/文件消息用户级实测、非视觉模型带图 400 的 UX 提示。
