# 更新记录 · v3.5.2「首启引导 · 使用文档 · 安全与日志修复」

> [!WARNING]
> 本版新增五步首启引导与 19 章桌面端使用文档，并修复诊断包凭据泄露、画图 Key 明文落盘、主动发起日志刷屏、更新检查不走代理等问题。v3.5.0 新增的群聊全接收、远程面板、设置页自动保存等仍在持续真机实测——遇到问题请到 [Issues](https://github.com/wens6515/weixin-wechat-wxauto-ocr-xiaoli/issues) 提交（附日志与复现步骤）。需要稳定版可回退 v3.4.0；只想避开本轮改动可回退 v3.5.1。

## 五步首启引导

首次启动不再只填「三个工作目录 + 昵称」，改为五步：

1. **环境检查**：微信窗口/进程、进程在但找不到主窗口、窗口最小化、显示缩放；建议开启微信「语音自动转文字」。
2. **模型接入**：Provider、Base URL、API Key、模型、测试连接（只读模型列表，不消耗 token）。
3. **身份与角色卡**：微信名称、角色卡选择；先切卡再写昵称，避免昵称写到旧卡。
4. **微信文件接收目录（可选）**：不配置也能聊天，只是收文件功能不可用；任务工作目录不在这里。
5. **完成与启动**：检查清单、「初始化并开始监听」、「只初始化，稍后开始」、「查看使用文档」。

配套：

- 新增 `onboarding_done` 标记：新装为 `false`，已有配置升级时自动视为完成，不打扰老用户。
- 设置页顶部新增「新手引导 / 使用文档」两个常驻按钮；首启引导也可随时重跑。
- 首页配置 banner：只在引导未完成或模型未配置时出现；文件目录是可选项，不在首页长期打扰。
- 任务工作目录与天枢配置仍由「开启任务桥后的天枢配置引导」处理，不进入首启。
- 服务商下拉框补齐 6 个预设：DeepSeek、智谱 GLM、通义千问、月之暗面 Kimi、豆包（火山引擎）、硅基流动；已有配置优先保留。

## 安全与隐私

- **诊断包脱敏**：`remote_token`、`image_gen_api_key`、`web_proxy` 里的账号密码统一打码；诊断包导出的 `config.json` 不再包含这些明文。
- **画图 API Key 加密**：`image_gen_api_key` 纳入 Windows DPAPI 加密落盘；`config.json.bak` 里的旧明文 Key 也会在同一次保存时迁成密文。
- `config.json.bak` 落盘前剥离派生投影，避免嵌套 Key 残留。

## 日志与更新

- **主动发起日志刷屏**：安静时段不再每 0.5 秒写一条 `[主动] 安静时段，跳过`；空队列直接返回，同一次安静时段只记一行。
- **退避日志去重**：同一会话的退避窗口只在该窗口第一次跳过时记一行，不再每轮刷 `bot.log`；避免 2MB 轮转把真正的错误现场轮掉。
- **更新检查走代理**：`check_latest_release` 接入 `web_proxy`，与安装包下载阶段同口径；GitHub API 直连不稳时也能检查更新。
- 修正主动发起「末尾 system」的过期注释；设置页补「对话行为」锚点。

## 升级方式

覆盖安装即可，`config.json`、`cards/`、`memory.json`、`memory_deep/`、`memory_global.json`、`reminders.json`、`usage.db` 保留。已有配置升级时 `onboarding_done` 自动为 `true`，不会自动弹首启；想体验引导可到「设置 → 新手引导」重跑。想测试全新首启，请先备份并移走 `config.json`。
