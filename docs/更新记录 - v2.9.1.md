# v2.9.1「性能焕新」更新记录

## 性能

### 背景层静态化：风扇常转根治

- 症状：窗口在桌面渲染时风扇持续响，最小化/托盘才安静
- 根因：背景粒子动画以 30fps 定时器每帧整窗重绘，壁纸每帧重缩放；部分壁纸配色下粒子视觉上不可见但 CPU 持续高占用
- 修复：背景一次性合成静态层（壁纸缩放 + 遮罩 + 主题渐变 + 主题装饰），只在改窗口尺寸 / 换壁纸 / 换主题时重建——窗口可见时**零重绘、零定时器**，与最小化同等安静
- 粒子效果整体移除；主题氛围感改由每套一件**静态签名装饰**承担（深海气泡群 / 赛博地平线网格 / Tokyo Night 雨线 / 星夜星点 / 水墨晕染 / 奶油圆点 / 薄荷波浪），随静态层一次合成，同样零逐帧成本

### 消息框检测向量化

- 红圈几何检测里的连通域分析换 numpy 段级实现，实测快 3.4~6.2 倍，逐场景结果与原实现一致

### 页面切换动画提速

- 时长 420ms → 240ms、帧间隔 12ms → 33ms（连续切换的 CPU 开销降约八成）、缓动改 ease-out cubic更利落
- 方向感知推挤过渡保留——半透明淡入类过渡在壁纸上会读成「黑块移动」，真机实测废弃，勿改回

## 新功能

### 按聊天覆盖功能开关（三态）

- 全局功能开关（语音发送 / 联网搜索 / 任务桥 / 状态监视）之外，可对单个聊天单独设置：**跟随全局 / 强制开 / 强制关**
- 强制开优先于全局关（例如全局关语音、但某个聊天单独开）；强制关的聊天模型看不到对应工具，从根源不触发
- 入口：设置页「按聊天覆盖功能」——聊天下拉（有记忆的聊天）+ 四功能三态，保存即热生效，无需重启

### 聊天记录导出

- 记忆页可把**单个聊天**的全部记录导出为 Markdown（人读）或 JSON（机读）：近期对话、重要记忆、关键词索引、深层存档全量包含

### 触发器可视管理

- 首页新增「触发器」按钮（带活跃计数徽章），点开统一管理定时提醒与状态监视：类型 / 目标聊天 / 内容或条件 / 状态徽章 / 时间 / 行内暂停·恢复·删除 / 底部详情面板（含监视条目的轮询目标、判定方式、连续失败、终态证据）
- 活跃条目在前、终态沉底；终态条目只留删除（恢复无意义且会重发）
- 设置页原触发器表格移除，统一走管理器入口
