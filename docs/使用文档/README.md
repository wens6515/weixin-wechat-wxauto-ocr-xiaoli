# 小漓使用文档

小漓是一个运行在 Windows 上的微信 AI 机器人桌面应用：通过截图 + OCR 读取微信消息，调用你配置的大模型生成回复，并把任务投递给天枢 CLI 处理。它**不修改微信数据**，不使用 UIA / CDP / 本地数据库通道。

本文档面向**桌面端使用者**，覆盖控制面板里的每个功能、设置项、常见用法和排障步骤。开发者文档（源码运行、架构、测试）见仓库根目录的 README。

## 5 分钟上手

1. **安装**：下载 `xiaoli-setup-v*.exe`，双击安装（免管理员权限），从开始菜单或桌面启动小漓。
2. **首启引导**：按五步走完——环境检查、模型 API Key、微信名称/角色卡、微信文件接收目录（可选）、初始化并开始监听。
3. **开始使用**：给小漓发一条微信消息；需要看状态、日志、用量或改设置时，回到控制面板。

> 运行期间请保持微信窗口打开、**不要最小化**。小漓的视觉通道在微信最小化时是盲的；程序会把微信窗口大小固定在工作区右半屏，位置由你摆放。

## 阅读约定

- 界面按钮、开关、页面名用「」标出，例如「设置 → 群聊接收模式 → 全接收·自主」。
- `等宽字体` 表示文件、目录、配置键或命令。
- 「成本」指会产生模型 API 调用的功能；「估算消费」按内置价目计算，不等于平台账单。
- 文档不绑定具体版本号；版本差异见仓库 Releases 和 `docs/更新记录 - v*.md`。
