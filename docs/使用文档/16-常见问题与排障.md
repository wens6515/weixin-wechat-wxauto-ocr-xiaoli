# 16 常见问题与排障

本章按「现象 → 先看什么 → 怎么处理」组织。排障前先确认三件事：引擎在运行、微信窗口可见且没最小化、模型 Key 可用。

## 1. 完全不回复

1. 首页引擎状态是不是「运行中」？不是就点主按钮启动/恢复。
2. 微信窗口是不是最小化/被其他窗口完全遮挡？视觉通道需要看到微信。
3. 首页环境卡：微信是否检测到？模型是否配置？每日预算是否耗尽？
4. 看首页运行日志最后几行；再看 `bot.log` 里同时间段的 `[MSG]` / `[vision]` / `[退避]`。
5. 模型 API 401/429/5xx？到「模型」页测试连接；429 等一会儿或换模型。

## 2. 回复发错人 / 发到别的会话

小漓发送前会切到目标会话并读标题复验，确认不了就放弃。仍出现时：

- 运行期间不要手动切换微信会话/拖动窗口；
- 检查是否有任务成果正在回传（回传期间会暂停监听）；
- 把当时的 `bot.log` 片段附到 issue。

## 3. 图片/文件识别失败

- 图片：确认在消息区可见；重发一次；看日志是否有媒体捕获失败。
- 文件：确认「设置 → 文件目录 → 微信接收目录」指向微信实际目录；文件已下载完成；重发。
- 扫描版 PDF 没有文本层、加密 Office 文件提取为空，这是格式限制。
- 引用图片/文件：缩略图太小或被滚出视口时可能读不到；重发原图/文件。

## 4. 群里不回复 / 全接收不说话

- 仅 @ 模式：确认 `@` 的名称和「设置 → 小漓身份 → 微信名称」一致。
- 全接收·自主：要说话必须调用 `send_message` 等工具，直接输出文字不会发送；看日志「群聊发送」。
- 群聊判定：标题区括号人数是权威信号；群名不含「群/集团」且无人数的群可能被当私聊。
- 全接收费用高：活跃群可切回「仅 @」。

## 5. 语音问题

- 对方语音读不到：微信「设置 → 通用 → 语音自动转文字」没开。
- 发不出语音：TTS 端点/音色档案/VB-CABLE/胶囊检测任一环节失败都会回退文本；看日志 `[语音]`。
- 「始终语音」却收到文字：TTS 配置不齐时的预期回退。

## 6. API 错误

| 错误 | 常见原因 | 处理 |
|---|---|---|
| 401 | Key 错/过期/与 Base URL 不匹配 | 模型页重填并测试连接 |
| 400 `maximum context length` | 上下文超限 | 调低上下文预算、减少附件/历史、换大上下文模型 |
| 400 `reasoning_content` | 推理模型工具往返协议 | 升级到当前版本；仍出现附日志提 issue |
| 429 | 频率限制/余额不足 | 等待、换模型、降低主动发起/全接收频率 |
| 5xx / 网络错误 | 服务商故障/网络 | 重试；检查网络/代理；换服务商 |
| 402/余额不足 | 平台余额 | 到平台充值；用量页可查余额（支持的服务商） |

## 7. 消费/预算问题

- 消费是内置价目估算，不是账单；平台调价、自定义模型可能不准。
- 没有价目的模型不计入消费/预算，但 tokens/调用仍记录。
- 预算到了当天不再调用模型（红圈仍清）；第二天自动恢复。
- 缓存命中率只统计成功调用；失败请求不再污染命中率。

## 8. 更新/远程面板

- 检查更新失败：网络/代理；「设置 → 联网搜索 → 搜索代理」也会用于更新下载和检查（当前版本已接入）。仍失败就去 Releases 手动下载。
- 手机打不开远程面板：确认「局域网开放」、同一网段、防火墙端口、地址带 `?t=` 令牌。
- 令牌泄露：设置页「重置令牌」，旧链接立即失效。

## 9. OCR 读错/漏消息

- 微信窗口不要最小化、不要被遮挡、不要手动改大小（程序会固定为工作区右半屏）。
- 显示缩放变化后，程序会自动换算；仍异常时把「系统分辨率 + 缩放 + 截图」附到 issue。
- 滚动出消息区的消息读不到，这是视觉通道固有限制。
- 群名/昵称里的特殊符号可能被 OCR 读成变体；记忆键会做等价匹配，但极端符号仍可能分裂。

## 10. 任务桥问题

- 模型不投递任务：确认任务桥开关、该聊天没有按聊天覆盖关闭。
- 找不到天枢窗口：先打开 `rivet`，或用天枢配置引导打开；确认窗口标题。
- 任务卡住：看天枢窗口是否等待确认；检查任务目录；必要时删除任务重投。
- 成果没回传：检查 `result.json` 和任务目录内文件。

## 11. 提交 issue 需要什么

- 小漓版本（首页版本卡/`version.py`）。
- 微信版本、Windows 版本、系统分辨率与缩放。
- 复现步骤（越具体越好）。
- 日志页相关片段；必要时诊断包。
- **不要**贴 API Key、远程令牌、完整 `config.json`、含隐私的聊天记录/截图。

## 12. 回退

需要稳定版时到 Releases 下载旧版本覆盖安装；回退前备份 `config.json`、`cards/`、`memory.json`、`memory_deep/`。
