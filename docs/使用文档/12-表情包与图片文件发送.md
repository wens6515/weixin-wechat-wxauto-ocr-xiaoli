# 12 表情包与图片文件发送

本章解决：让小漓发表情包、AI 生成图片、把任务成果文件补发给你。

这三个能力都默认关闭；关闭时对应工具不声明，模型看不到。

## 1. 表情包

「设置 → 表情包」：

- 库位置：应用目录下的 `表情包\`。往文件夹里加 `png/jpg/gif` 即可扩充。
- 每种表情有一份描述与标签，用于模型挑选；新图可以点「AI 优化标签」让模型看图写描述（有 API 成本）。
- 「预览注入清单」查看模型实际会看到的内容（条数、token 估算）。
- 「管理表情包…」可添加图片、添加文件夹、打开库目录、编辑描述/标签。

发送模式：

| 模式 | 行为 | 适用 |
|---|---|---|
| 关闭 | 不声明 `send_sticker` | 不需要 |
| 清单注入 | 每次请求带上全部表情包清单，模型直接挑 | 库小、省一次往返 |
| 按需查询 | 模型先 `search_stickers` 拿候选，再挑 | 库大、省 token |

模型可以只回一张表情包，也可以表情包 + 文字一起回。表情包发送前会确认目标会话，确认不了就放弃。

## 2. AI 生成图片

「设置 → 图片与文件发送」打开「允许 AI 发图片/文件」，并填写：

- **画图接口**：OpenAI images 兼容端点，例如 `http://127.0.0.1:7860/v1/images/generations`。
- **画图模型**：服务端支持的模型名。
- **画图 API Key**：自部署服务可留空。

模型调用 `send_image` 时，小漓请求画图接口生成图片，再发到当前会话。端点/模型为空时，工具会回执告知能力不齐，不会静默失败。

## 3. 发送任务文件

同一个开关下，模型可以调用 `send_file` 把**任务工作目录内**的文件补发给你。

- 路径边界独立把守：目录外的文件发不了，防止提示词注入套走隐私文件。
- 适合「任务成果只回传了说明，文件想再要一次」的场景。
- 文件必须已经在任务目录里；不存在的路径会回执失败。

## 4. 安全与成本

- 表情包/图片/文件发送都会先确认目标会话，避免发错人。
- 画图接口可能按次计费，与聊天模型分开。
- `send_file` 只能读任务目录；不要把隐私目录设成任务目录。
- 表情包 AI 打标、画图都会产生额外调用。

## 5. 常见问题

| 现象 | 处理 |
|---|---|
| 模型不发表情包 | 检查模式不是「关闭」；库里有图；清单/查询结果可见 |
| 表情包发错人 | 发送前会 `_ensure_chat_active` 校验；确认不了会放弃；避免运行期间手动切微信 |
| 画图失败 | 检查端点/模型/Key；看运行日志；自部署服务确认在跑 |
| 发文件提示目录外 | `send_file` 只允许任务工作目录内；把文件放进任务目录 |
| AI 优化标签很慢 | 每张图一次视觉调用；库大时分批做，或手动填描述 |
