# 01 安装与首次启动

本章解决：安装小漓、走完第一次启动的新手引导、让引擎开始监听微信。

## 1. 准备工作

- Windows 10 或更高版本。
- 已安装并登录**微信 PC 4.x**。
- 一个 OpenAI 兼容的模型服务商（DeepSeek、智谱、通义、Kimi、豆包、硅基流动等），准备好 API Key。
- 如果要使用任务桥：另需 Node.js 和天枢 CLI（见 [09 任务桥](09-任务桥.md)）。

小漓不需要安装 Python，安装包已内置运行时、OCR 引擎和全部依赖。安装默认 per-user，免管理员权限。

## 2. 安装

1. 从 [Releases](https://github.com/wens6515/weixin-wechat-wxauto-ocr-xiaoli/releases) 下载 `xiaoli-setup-v*.exe`。
2. 双击运行，按向导选择安装位置（默认在 `%LOCALAPPDATA%\Programs\小漓`）。
3. 安装器会检测 Node.js；没有且你需要任务桥时，它会自动下载安装 Node.js LTS。
4. 从开始菜单或桌面启动小漓。首次启动会创建 `config.json`、`cards/`、`memory.json` 等运行时文件。

> 小漓是单实例应用。重复启动会提示「小漓已在运行」，请到系统托盘图标处打开控制面板。

## 3. 新手引导（五步）

首次启动会自动弹出「欢迎使用小漓」。也可以随时从「设置」页顶部点「新手引导」重新运行。

### 第一步：环境检查

界面会检查：

- **微信 PC 版**：是否检测到微信窗口/进程。如果微信没开、没登录，或窗口被最小化，会在这里提示。
- **显示缩放**：显示当前缩放档位。小漓按「逻辑像素 × 缩放」自适应，175% 是标定档，其他档位也能用。

建议同时到电脑版微信「设置 → 通用」开启**语音自动转文字**——开启后小漓才能读懂对方发来的语音消息。

任务工作目录、天枢 CLI **不在这一步**：任务桥默认关闭，开启任务桥后会有单独的天枢配置引导。

### 第二步：模型接入

1. 选择「服务商」（预设了 DeepSeek / 智谱 / 通义 / Kimi / 豆包 / 硅基流动）。
2. 确认或修改 Base URL。
3. 填入 API Key。Key 只保存在本机，落盘时用 Windows DPAPI 加密。
4. 选择或填写对话模型，例如 `deepseek:deepseek-flash`。
5. 点「测试连接」——它只读取模型列表，不消耗 token。看到「连接成功」即可。

可以点「下一步」先跳过；未配置 Key 时小漓无法回复，首页会持续显示「模型未配置」提示。之后可到「模型」页补配置。

### 第三步：身份与角色卡

- **微信名称**：小漓在微信里的自称，也是群里 `@` 她时用的称呼。建议填成你微信好友里能 @ 到的名字。
- **角色卡**：决定她是谁、怎么说话。先用默认「小漓」即可；之后到「角色卡」页编辑人设、温度、top_p、历史条数，或导入别人分享的卡。

### 第四步：微信文件接收目录（可选）

对方发来的文件，小漓会在这个目录里按文件名查找。路径可以在电脑版微信「设置 → 文件管理」里看到。

- 不配置也能正常聊天，只是收文件功能不可用。
- 换过微信存储位置（例如把文件放到 `D:\微信文件`）的用户请手动「浏览…」选择。
- **任务工作目录不在这里**；它属于任务桥，见 [09 任务桥](09-任务桥.md)。

### 第五步：完成与启动

完成页会汇总检查结果：微信、模型、角色卡、文件目录。你可以：

- 点「初始化并开始监听」：小漓会定位微信窗口、开始截图监听，然后启动自动回复。
- 点「只初始化，稍后开始」：只初始化引擎，回首页后点主按钮启动。
- 点「跳过引导」：保存完成标记，但不初始化；完成页会标出未完成项（缺模型时首页会持续提示）。

初始化失败时，界面会给出修复指引（常见原因：微信没开、没登录、窗口最小化、显示缩放/窗口尺寸异常）。按提示处理后回首页重试。

## 4. 引擎状态与托盘

首页主控卡的状态：

| 状态 | 含义 | 操作 |
|---|---|---|
| 尚未初始化 | 还没连接微信 | 点主按钮「初始化引擎」 |
| 正在初始化 | 正在定位窗口/加载记忆 | 等待；失败会显示原因 |
| 已就绪 | 已连接，尚未开始监听 | 点主按钮「启动 bot」 |
| 运行中 | 正在监听并自动回复 | 点主按钮可暂停 |
| 已暂停 | 监听暂停，红圈不会被处理 | 点主按钮恢复 |
| 初始化失败 | 连接微信失败 | 看错误提示，处理后重试 |

托盘菜单：

- 「打开控制面板」：显示/聚焦窗口。
- 「暂停回复 / 恢复回复」：不打开窗口也能控制。
- 「退出小漓」：退出进程（会先停引擎）。

## 5. 数据放在哪

| 内容 | 默认位置 |
|---|---|
| 安装目录 | `%LOCALAPPDATA%\Programs\小漓` |
| 配置 | 安装目录下 `config.json`（API Key 加密） |
| 角色卡 | 安装目录下 `cards\` |
| 记忆 | 安装目录下 `memory.json`、`memory_deep\`、`memory_global.json` |
| 触发器 | 安装目录下 `reminders.json` |
| 用量 | 安装目录下 `usage.db` |
| 表情包 | 安装目录下 `表情包\` |
| 壁纸 | 安装目录下 `壁纸\` |
| 任务目录 | 默认在安装目录下的 `wxauto`（可在设置页改） |

更完整的隐私与备份说明见 [15 隐私、数据与升级](15-隐私数据与升级.md)。

## 6. 升级与回退

- **升级**：首页检测到新版本后点「一键更新」，或到 Releases 下载新安装包覆盖安装。`config.json`、`cards/`、`memory.json`、`memory_deep/`、表情包、壁纸都会保留。
- **回退**：到 Releases 下载旧版本安装包覆盖安装。如果新版本改过配置结构，回退后可能丢失部分新字段，建议先备份 `config.json` 和 `cards/`。
- 安装包是 per-user 的，不需要管理员权限；卸载不会自动删除你的记忆和角色卡。

## 7. 首次启动常见问题

| 现象 | 处理 |
|---|---|
| 一直提示「未检测到微信窗口」 | 打开微信并完成登录；确认不是只有进程没有主窗口；窗口不要最小化 |
| 初始化失败，提示窗口尺寸/缩放异常 | 把微信窗口恢复到正常大小；小漓会自动把窗口尺寸固定为工作区右半屏 |
| 测试连接 401 | API Key 填错、过期，或服务商与 Base URL 不匹配 |
| 测试连接超时/网络错误 | 检查网络；模型 API 不走「联网搜索」里的代理设置，需要系统代理或换网络 |
| 完成引导后小漓不说话 | 确认引擎是「运行中」，模型 Key 已配置，微信窗口没有最小化；看首页运行日志 |
| 收文件提示「文件下载失败」 | 检查「设置 → 文件目录 → 微信接收目录」是否指向微信实际的文件目录 |

更多排障见 [16 常见问题与排障](16-常见问题与排障.md)。
