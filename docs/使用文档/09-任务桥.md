# 09 任务桥

本章解决：让天枢处理复杂任务、任务怎么投递/回传、任务目录怎么配、出问题怎么查。

## 1. 任务桥是什么

当消息是「需要动手做出来」的任务（做一个网站、做 PPT、写代码、分析数据、整理文件、生成文档）时，模型可以调用 `dispatch_task` 把任务投递给**天枢 CLI**。天枢在任务目录里工作，写进度和结果，小漓轮询后把文字说明 + 成果文件回传微信，并归档到 `sent/`。

任务桥默认**关闭**。关闭时模型看不到 `dispatch_task` 工具，普通聊天、图片、文件、语音、搜索、提醒等不受影响。

## 2. 前置条件

1. Node.js（安装小漓时可选自动安装；也可自行安装）。
2. 天枢 CLI：`npm install -g tianshu-tui`，命令为 `rivet`。
3. 在「设置 → 任务桥」打开「启用任务桥」。
4. 首次打开会弹出「天枢配置引导」：
   - 点「一键安装天枢」自动安装（首次约 1–3 分钟）。
   - 点「① 打开天枢 CLI」，在窗口里选模型、填 API key、回车确认。
   - 点「② 我已配置完成」。

也可以在「设置 → 任务桥 → 天枢配置引导」随时重跑。

## 3. 任务目录

「设置 → 文件目录 → 任务工作目录」默认在**安装目录下的 `wxauto`**（便携默认：程序拷到哪，任务目录跟到哪）。

- 天枢的工作目录（`tianshu_workdir`）自动跟随任务目录的父目录，保证路径安全检查通过。
- 每个任务一个子目录，里面有任务描述、附件、`result.json`、成果文件、`progress.json`（可选）。
- 回传成功后，成果归档到任务目录的 `sent/`。
- 任务进行中，小漓会暂停消息监听，防止切窗打断发送；任务完成后有短暂缓冲期。

任务工作目录的配置**不在首启引导里**：任务桥默认关，只有你确实要使用时才需要配；首次开启任务桥时的天枢引导会处理。

## 4. 任务流转

1. 模型判定任务 → 调用 `dispatch_task`。
2. 小漓发一条占位回复（如「收到任务啦，正在处理中」），把任务描述和附件写入任务目录。
3. 唤起天枢 CLI 窗口，发送触发指令（默认「开始处理」）。
4. 天枢处理，按需写 `progress.json`。
5. 主循环每 5 秒轮询任务目录：
   - `progress.json` 有新写入 → 回传一条阶段进度（无节流）。
   - `result.json` 出现 → 先归档 `sent/`，再回传文字 + 成果文件。
6. 回传完成，恢复消息监听。

短任务不写 `progress.json` 就没有进度消息，直接等结果。

## 5. 任务页

导航栏「任务」：

- 顶部三个数字：天枢处理中 / 已完成待回传 / 已归档。
- 表格：任务 ID、状态、描述、时间。
- 可刷新、删除任务（删除会移除任务目录，谨慎操作）。
- 「打开任务目录」在设置页任务桥卡片里。

## 6. 相关配置

| 配置/设置 | 默认 | 说明 |
|---|---|---|
| 启用任务桥 | 关 | 总开关；关闭 = 不声明 `dispatch_task` |
| 任务工作目录 | 安装目录下 `wxauto` | 任务子目录与 `sent/` 的根 |
| 天枢窗口标题 | 空 | 空 = 启动时交互选择；也可在引导里选 |
| 触发指令 | `开始处理` | 唤起天枢后发送的指令 |
| 轮询间隔 | 5 秒 | 任务结果/进度轮询 |
| 首轮提示词 | 内置模板 | 可自定义文件，让天枢先读任务目录的 README |

首轮提示词用于让天枢读任务目录里的协议文档；首页「首轮提示词」卡可重发一次。

## 7. 安全边界

- 任务桥只把小漓收到的任务描述和附件写入任务目录；不会把整个聊天记录交给天枢。
- 成果文件只从任务目录回传；`send_file` 工具也只允许任务工作目录内的文件，目录外发不了。
- 任务目录里可能有你的文档和成果，注意备份与访问权限。

## 8. 常见问题

| 现象 | 处理 |
|---|---|
| 模型不投递任务 | 确认「启用任务桥」已开；该聊天没有被「按聊天覆盖」关掉；模型可能判断为普通聊天 |
| 提示找不到天枢窗口 | 先打开天枢 CLI（`rivet`），或在「天枢配置引导」里点「① 打开天枢 CLI」；确认窗口标题 |
| 任务一直「处理中」 | 看天枢窗口是否卡住/等确认；检查任务目录里的文件；必要时删除任务重投 |
| 没有进度消息 | 天枢只在关键节点写 `progress.json`；短任务没有进度是正常的 |
| 成果文件没回传 | 检查 `result.json` 是否写了成果文件路径；文件必须在任务目录内 |
| 任务完成后小漓还在暂停 | 缓冲期结束会自动恢复；检查首页状态 |
