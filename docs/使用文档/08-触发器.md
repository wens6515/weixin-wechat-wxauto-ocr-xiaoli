# 08 触发器

本章解决：定时提醒、状态监视（盯网页）怎么创建、怎么触发、怎么管理。

触发器有两种：`time`（定时）和 `condition`（状态监视）。两者到点/达成/到期时，系统都会把事件回递给模型，由模型按人设生成回复——不预写固定文案。

## 1. 定时提醒

### 对话里创建

直接对小漓说：

- 「明天下午 3 点提醒我查成绩」
- 「每天早上 8 点叫我起床」
- 「每周五晚上 7 点提醒我交周报」

模型会把相对表达换算成绝对时间，调用 `set_reminder`，参数：

| 参数 | 说明 |
|---|---|
| `kind` | `time` |
| `time` | `YYYY-MM-DD HH:MM`（24 小时制） |
| `repeat` | `once` / `daily` / `weekly`，默认 `once` |
| `content` | 提醒内容（可选；对话创建时靠创建时的历史） |

### 设置页手动创建

「设置 → 定时与监视 → 管理触发器 → 新增定时提醒」：选目标聊天、填内容、选时间、选重复规则。界面创建会把**你填的内容**一并交给模型，模型不必猜要说什么。

### 触发与补发

- 到点后主循环在发送节点切到目标会话、读标题复验，确认后发送。
- 暂停/关机错过的提醒有 5 分钟补发宽限；超过宽限按「已错过」处理并回递告知。
- 重复提醒触发后会计算下一次时间；`once` 触发后进入终态。

## 2. 状态监视

用于「如果一个网页上出现了某个条件，就告诉我」：

- 「如果一会儿下雨了提醒我去拿快递」
- 「盯着这个商品页面，降价了告诉我」
- 「这个页面出现『报名』两个字时提醒我」

### 创建规则

模型创建前必须先用 `web_search` 找到页面，再用 `web_fetch` 看过实际内容；轮询期只访问这个固定 URL，不再调用搜索引擎。

参数：

| 参数 | 说明 |
|---|---|
| `url` | 固定轮询的网页 |
| `condition` | 自然语言条件原文（判定/到期回递的依据） |
| `judge` | `local`（本地关键词，零 API）或 `api`（每轮调模型判定，有成本） |
| `match_type` | `present`（出现任一关键词即达成）/ `absent`（关键词全部消失即达成） |
| `met_keywords` | `judge=local` 必填，按页面实际措辞给全同义形式 |
| `scope_start` / `scope_end` | 页面文本原文的切片标记，只匹配两标记之间，隔离未来时段 |
| `interval_seconds` | 轮询间隔，默认 60，最小 10 |
| `expire_at` | 截止时间；不填默认 7 天后 |

页面同时包含当前和未来信息（如天气预报「今天暴雨…周六晴」）时，必须给 `scope_start`/`scope_end`，否则会被未来预报误触发。

### 触发与终止

- 条件达成 → 回递告知。
- 到 `expire_at` → 回递「到期」。
- 连续抓取失败达到上限 → 标记失效并回递。
- 页面改版、措辞大改可能提前终止或拖到截止，两种情况都会回递说明。

## 3. 管理触发器

- 首页「触发器」卡：定时/状态监视的数量和进度。
- 「设置 → 定时与监视 → 管理触发器…」：表格查看类型、目标聊天、内容/条件、状态、时间；可启用/暂停/删除。
- 「模型管理触发器」三态：
  - `关闭`：模型只能创建，不能查询/取消/修改。
  - `仅工具`：注入 `manage_reminder` 工具，模型被问到时可以 list 再操作。
  - `清单注入`：工具 + 活跃触发器清单随请求注入尾区，模型能直接拿 id 操作，也能主动提起已有约定。

「清单注入」推荐给经常让小漓改提醒的用户；如果觉得每次请求多带清单浪费 token，可以选「仅工具」。

## 4. 成本

| 类型 | 成本 |
|---|---|
| 定时提醒创建/触发 | 触发时一次回递 API 调用 |
| 状态监视 local 判定 | 轮询本身零 API；触发/到期回递一次调用 |
| 状态监视 api 判定 | 每轮一次小调用 + 触发回递 |
| 模型管理触发器 | 工具往返，按正常调用计费 |

「状态监视」总开关在「设置 → 定时与监视」；关闭时创建 `kind=condition` 会被拒绝并友好告知。

## 5. 常见问题

| 现象 | 处理 |
|---|---|
| 到点没提醒 | 检查触发器是否启用、目标聊天是否存在、引擎是否在运行；看运行日志 |
| 提醒发错人 | 发送前会切会话+标题复验，确认不了会放弃；避免运行期间手动切微信 |
| 状态监视一直不触发 | 页面改版/关键词不匹配；用 `web_fetch` 看实际措辞后重建；检查 scope 切片 |
| 被未来预报误触发 | 创建时给 `scope_start`/`scope_end`，把匹配范围圈到当前时段 |
| 反复抓取失败 | 页面需要登录/反爬/代理；换稳定页面，或改用 `api` 判定 |
| 模型擅自改提醒 | 把「模型管理触发器」调成「关闭」；它就只能创建不能改 |
