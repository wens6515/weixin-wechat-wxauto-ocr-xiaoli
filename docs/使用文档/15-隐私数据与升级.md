# 15 隐私、数据与升级

本章解决：小漓把数据存在哪、诊断包包含什么、怎么备份/迁移、怎么升级/回退。

## 1. 数据文件

默认都在安装目录（`%LOCALAPPDATA%\Programs\小漓`）：

| 文件/目录 | 内容 | 是否含敏感信息 |
|---|---|---|
| `config.json` | 全部配置；聊天/画图 API Key 用 DPAPI 加密 | 是（DPAPI 密文；远程令牌等仍是明文） |
| `config.json.bak` | 上一次配置备份 | 同上 |
| `cards/` | 角色卡（人设、模型、昵称） | 可能含个人信息 |
| `memory.json` | 近期对话、重要记忆、关键词索引 | 是（聊天内容） |
| `memory.json.bak` | 上一次记忆备份 | 是 |
| `memory_deep/` | 深层存档，按聊天分 jsonl，永不删除 | 是（聊天内容） |
| `memory_global.json` | 全局记忆 | 是 |
| `chat_meta.json` | 会话群聊标记缓存 | 低 |
| `persona_state.json` | 状态层情绪/精力 | 低 |
| `reminders.json` | 定时提醒/状态监视 | 是（提醒内容、URL） |
| `usage.db` | 调用记录（模型、token、耗时、成败） | 低（不含聊天内容） |
| `bot.log` | DEBUG 全量日志，含聊天文本/工具细节 | 是 |
| `bot_run.log` | INFO 运行日志，前端日志页读取 | 是（含聊天摘要） |
| `表情包/`、`壁纸/` | 本地素材库 | 低 |
| 任务工作目录 | 任务描述、附件、成果、`sent/` | 是（你的文档） |

记忆/角色的备份：复制 `config.json`、`cards/`、`memory.json`、`memory_deep/`、`memory_global.json`、`reminders.json` 即可。**API Key 是 DPAPI 按 Windows 用户加密的，换用户/换机后需要重填**；只复制配置文件不能迁移 Key。

## 2. 日志

- 两轨日志：`bot.log`（DEBUG 全量，排障用）和 `bot_run.log`（INFO，前端日志页）。
- 每个文件 2MB 轮转，保留 2 份历史。高频 DEBUG 会加快轮转；如果发现 `bot.log` 很快被刷满，先看是否有异常高频日志。
- 前端「清空」只清显示，不清磁盘文件。

## 3. 诊断包

「日志」页 →「导出诊断包」会生成一个 zip，包含：

- `info.json`：版本、Python/是否打包、引擎状态、微信窗口位置/缩放、主题等。
- `config.json`：**脱敏副本**。聊天/画图 API Key、Provider Key、远程令牌、代理 URL 里的账号密码都会打码；其余配置原样。
- `bot_run_tail.log`：最近 400 行 INFO 日志。
- `wechat_window.png`：微信窗口截图（best-effort）。

诊断包是为排障设计的，但日志和截图仍可能含聊天内容/联系人名。**发到公开 issue 前请自己看一遍**；如有隐私内容，只贴相关片段。

## 4. 升级

- 首页「检查更新」→「一键更新」：下载安装包、校验大小、拉起安装器、退出当前进程。
- 也可以到 Releases 下载安装包覆盖安装。
- 升级保留：`config.json`、`cards/`、`memory.json`、`memory_deep/`、`memory_global.json`、`reminders.json`、`usage.db`、表情包、壁纸。
- 升级后首次启动可能会做配置迁移（旧键改名/补默认值）；迁移会写回 `config.json`，建议升级前备份。
- 任务桥、语音、远程面板等开关保持原值；新版本新增的开关用默认值。

## 5. 回退

- 到 Releases 下载旧版本安装包覆盖安装。
- 旧版本可能不认识新版本写入的配置键（一般会忽略），但新功能数据可能丢失；回退前备份。
- 如果回退后 API Key 不可用，重新在「模型」页填一次。

## 6. 清理与卸载

- **清空记忆**：「记忆」页「清空全部」/「清空此会话」，或「设置 → 对话记忆 → 清空全部记忆」。运行中清空会同时清内存，避免节流写盘把旧记忆写回。
- **清空用量**：「用量」页「清空」。
- **删除任务**：「任务」页删除单个任务；会移除任务目录。
- **卸载**：Windows 设置 → 应用 → 小漓。卸载不会自动删除安装目录里的记忆/角色卡；需要彻底清理请手动删除安装目录（先备份）。

## 7. 隐私建议

- 不要把 `config.json`、`bot.log`、`memory.json`、诊断包直接发到公开渠道。
- 远程面板令牌等同密码；泄露后立即在设置页重置，并检查是否有异常访问。
- 任务工作目录可能包含你的文档和成果，注意目录权限与备份。
- 使用共享记忆池前，确认你接受「不同聊天的记忆可能互相可见」。
