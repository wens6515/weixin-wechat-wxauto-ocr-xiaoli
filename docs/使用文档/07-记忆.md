# 07 记忆

本章解决：小漓记得什么、记忆存在哪、怎么查看/编辑/清理、长记忆三层怎么工作。

## 1. 记忆分几层

| 层 | 作用 | 默认 |
|---|---|---|
| 近期对话（recent） | 每次请求注入的最近窗口，约 30~60 条浮动 | 开 |
| 深层存档（deep） | 溢出近期窗口的消息永久追加到 `memory_deep/<聊天>.jsonl`，永不删除 | 开 |
| 重要记忆（important） | 压缩线程从深层记忆提炼的长期事实，常驻上下文 | 依赖压缩开关 |
| 关键词索引（index） | 压缩产出的「关键词 → 记忆」，命中时注入 | 依赖压缩开关 |
| 全局记忆 | 跨聊天常驻的通用事实（关于小漓自己/主人/世界） | 默认关 |
| 共享记忆池 | `recall_memory` 可跨聊天检索其他会话的记忆 | 默认关 |

## 2. 近期窗口与滚动

「设置 → 对话记忆」：

- **近期保留条数**：默认 30；窗口在 30~60 之间波动。
- **滚动步长**：默认 30。攒满「保留条数 + 步长」时，把最旧的一段一次性弹出、归档进深层存档。这样两次滚动之间注入序列是「旧前缀 + 尾部追加」，模型前缀缓存命中更高；步长设为 0 就是到量逐条滚动。
- **深层存档**：关闭后溢出消息直接丢弃（不推荐）。

## 3. 记忆压缩

「记忆压缩」默认关闭，会产生额外 API 调用。开启后：

- 每攒满「每压缩条数」（默认 30）调一次压缩模型。
- 压缩模型留空 = 跟随当前聊天模型；也可以单独指定更便宜的模型。
- 产出「重要记忆」（上限默认 20 条，常驻上下文）和「关键词索引」（命中时注入）。
- 压缩提交会改写重要记忆/索引，但注入位置在历史之后的尾区，尽量不打碎前缀缓存。

关键词召回受措辞差异限制；模型还可以调用 `recall_memory` 按需检索深层存档，作为兜底。

## 4. 全局记忆与共享池

- **全局记忆**：开启后模型可调用 `save_global_memory` 写入；全局块对**所有聊天**注入。记忆页可以注入、编辑、删除，便于审计。
- **共享记忆池**：开启后 `recall_memory` 可以检索其他聊天的记忆（含深层存档），结果带来源聊天名。各聊天内容会互相可见——开启即接受这个边界。

两个开关默认都关闭，在「设置 → 对话行为与跨聊天记忆」打开。

## 5. 记忆页

导航栏「记忆」：

- 左侧是会话列表，显示近期/深层/重要/索引数量。
- 「概览」显示重要记忆、近期对话、关键词索引。
- 「深层存档」支持搜索、分页加载；可以删除指定条目。
- 「注入记忆」：手动添加重要记忆（常驻）或深层存档（仅检索）。
- 「编辑」任意条目；「清空此会话」/「清空全部」。
- 「绑定角色卡」：给单个聊天绑定不同角色卡（人设/模型/参数），与全局活跃卡分开。
- 「导出」：导出该聊天的记忆 Markdown。

## 6. 记忆是怎么进模型的

一次请求的布局（从稳定到变化）：

1. system 人设（角色卡）
2. system 回复纪律
3. 历史（近期窗口，带 `[时间]` 前缀）
4. system 重要记忆
5. system 相关记忆（关键词命中）
6. system 全局记忆 / 全局命中
7. system 当前时间
8. system 状态层（开启时）
9. system 触发器清单/表情包清单（按开关）
10. user 当前消息

这样「人设 + 历史」是稳定前缀，当前时间/状态/清单在尾区，模型缓存命中更高。

## 7. 什么不会写进记忆

- 主动发起的「sys：距上次聊天 X」只是本次调用文本，不写记忆。
- 群聊全接收沉默时不写 `[已读未回复]` 之类的标记。
- 工具循环的中间往返只存在于本次调用，不写历史。
- 主动发起决定不发时，不写任何历史。

## 8. 数据文件与隐私

- `memory.json`：近期/重要/索引（原子写 + `.bak`）。
- `memory_deep/<聊天>.jsonl`：深层存档，追加写，永不删除。
- `memory_global.json`：全局记忆。
- `chat_meta.json`：会话群聊标记缓存，不属于记忆内容。
- `persona_state.json`：状态层情绪/精力。

备份、清理、迁移见 [15 隐私、数据与升级](15-隐私数据与升级.md)。

## 9. 常见问题

| 现象 | 处理 |
|---|---|
| 小漓忘了之前说的事 | 近期窗口滚动/压缩；让它 `recall_memory` 检索；检查深层存档是否开启 |
| 记忆里出现奇怪的 OCR 变体 | 记忆键保留会话名原文，查找做等价匹配；记忆页可直接编辑 |
| 压缩成本高 | 关闭压缩，或指定便宜模型，或调大「每压缩条数」 |
| 共享池看到别的聊天内容 | 这是开关的设计语义；不需要就关闭 |
| 清空后还在回复旧内容 | 确认引擎在运行中清空（会同时清内存）；必要时重启引擎 |
