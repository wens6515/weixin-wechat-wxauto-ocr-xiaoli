# 14 外观与主题

本章解决：换主题、换壁纸、调透明度/毛玻璃/字号、跟随系统深浅色。

## 1. 主题

「设置 → 外观主题与壁纸」有 7 套主题：

| 主题 | 风格 |
|---|---|
| 深海小漓 | 默认深蓝 |
| 霓虹夜行 | 高对比霓虹 |
| Tokyo Night | 深夜蓝紫 |
| 星夜紫金 | 深色 + 金色点缀 |
| 墨染 | 浅色水墨 |
| 奶油晨光 | 浅色奶油 |
| 薄荷气泡 | 浅色薄荷 |

点击缩略图即时生效并保存；切换主题会按主题推荐壁纸（库里有同名文件才应用，没有就保持当前壁纸）。

## 2. 壁纸

- 壁纸库自动收录应用目录下的 `壁纸\` 文件夹。
- 「导入壁纸…」把图片复制进壁纸库；「清除壁纸」恢复无壁纸/纯色。
- 支持常见图片格式（png/jpg/webp 等）；大图会按最长边缩放显示。
- 壁纸不影响微信本身的深浅色识别——小漓单独检测微信主题，与面板主题无关。

## 3. 透明度与视觉效果

| 滑块 | 作用 |
|---|---|
| 卡片透明度 | 玻璃卡片的不透明度 |
| 壁纸浓度 | 壁纸叠加层的浓度 |
| 毛玻璃程度 | 卡片背景模糊强度 |
| 面板浓度 | 面板底色浓度 |
| 界面字号 | 小 / 标准 / 大 |

「跟随系统深浅色」：开启后面板跟随 Windows 应用深浅色模式；关闭则固定用当前主题。

## 4. 常见问题

| 现象 | 处理 |
|---|---|
| 换了主题但壁纸没变 | 该主题没有推荐壁纸，或壁纸库没有同名文件；手动选壁纸 |
| 壁纸太亮/看不清字 | 调高卡片不透明度/面板浓度，或降低壁纸浓度 |
| 导入壁纸失败 | 确认是图片格式；文件可能被占用/路径无权限 |
| 字号改了没生效 | 部分表格/图表有最小字号；刷新页面或重启控制面板 |
| 跟随系统不生效 | Windows 未开启应用深浅色，或当前主题不支持；手动切换 |
