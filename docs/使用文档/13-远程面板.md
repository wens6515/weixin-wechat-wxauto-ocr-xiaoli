# 13 远程面板

本章解决：用手机/平板浏览器看状态、日志、用量、触发器，暂停/恢复回复。

远程面板默认关闭。它是桌面端控制面板的同一套页面，通过局域网 HTTP + 访问令牌访问；不依赖云服务。

## 1. 开启

「设置 → 远程面板」：

1. 打开「开启面板服务」。默认只监听 `127.0.0.1`（本机）。
2. 需要手机访问时，再打开「局域网开放」——绑定全部网卡。
3. 确认「服务端口」（默认 8765）。
4. 复制「访问地址（含令牌）」，在手机浏览器打开。
5. 换设备/令牌泄露时，点「重置令牌」，旧链接立即失效。

访问地址形如 `http://<电脑局域网IP>:8765/?t=<令牌>`。

## 2. 能做什么

- 看首页引擎状态、运行日志。
- 看用量统计、触发器列表。
- 暂停/恢复回复。
- 同一套导航页也能打开其他页面；但**建议远程只做查看和暂停/恢复**，改配置、编辑记忆、删除任务等敏感操作回桌面端做，避免误触和令牌泄露带来的风险。

## 3. 安全边界

- 明文 HTTP + 访问令牌，**不要做公网端口映射**。需要外网访问请用 Tailscale / ZeroTier 等组网，再按局域网地址访问。
- 令牌等同密码：拿到令牌的人可以操作面板。不要把带 `?t=` 的链接发到群里、截图或公开 issue。
- 只在自己信任的局域网开启「局域网开放」；公共 Wi-Fi 下建议关闭。
- 手机浏览器可能把令牌存到本地存储；共用设备用完可清除站点数据/重置令牌。
- 防火墙可能拦截端口；手机打不开时先检查 Windows 防火墙是否允许小漓/端口。

## 4. 连接不上

| 现象 | 处理 |
|---|---|
| 手机打不开地址 | 确认「局域网开放」已开、手机和电脑在同一网段、防火墙放行端口 |
| 提示未授权/401 | 令牌错误或已重置；重新复制设置页的完整地址 |
| 页面能开但没数据 | 检查地址是否带 `?t=`；看桌面端日志是否有远程请求 |
| 换了路由器/IP 变了 | 重新复制访问地址；建议给电脑固定局域网 IP |
| 不想用了 | 关闭「开启面板服务」；重置令牌 |

## 5. 与本地窗口的区别

- 本地窗口是 pywebview，直接调用后端；远程是 HTTP/SSE。
- 远程模式不支持原生文件选择对话框、打开资源管理器、退出进程等本地语义操作。
- 远程页面会带一个标记，前端据此走 HTTP 通道；两种模式共用同一套界面逻辑。
