# 10 模型与用量

本章解决：怎么接模型、怎么换模型、怎么看调用量和花费、预算怎么设。

## 1. 模型接入

「模型」页：

1. 在「Provider 路由表」里添加或编辑服务商：
   - 名称、Base URL、API Key、模型列表（逗号分隔）、ID。
   - 预设：DeepSeek / 智谱 GLM / 通义千问 / 月之暗面 Kimi / 豆包 / 硅基流动。点预设芯片即可添加，再填 Key。
2. 点「测试第一行连接」：GET `{Base URL}/models`，列前 20 个模型；不消耗 token。
3. 点「保存并应用」：写回 `config.json`，热更新当前运行中的 bot。
4. 在「当前对话模型」里选 Provider、填模型，保存。

模型名支持 `provider:model` 形式（例如 `deepseek:deepseek-flash`）；发请求时会剥掉前缀，用纯模型名。模型 ID 以各平台当前在售为准。

## 2. API Key 安全

- Key 只保存在本机；落盘时用 Windows DPAPI 加密（`dpapi:` 前缀）。
- 换 Windows 用户/换机后旧 Key 解不开，会变成空 Key，需要重填。
- 界面显示 Key 时会遮蔽（`sk-***1234`）。
- 诊断包导出时会打码；不要把 `config.json` 直接发到公开渠道。

## 3. 上下文与回复上限

「模型」页还能设置：

- **上下文预算**（`max_context_tokens`）：单次请求的估算 token 上限，默认 100000；超限从最旧历史开始裁剪。大上下文模型可调高。
- **回复长度上限**（`reply_max_tokens`）：聊天/视觉两条链路共用的物理上限，默认 40000；包含推理模型的思考 token。回复长短主要由回复纪律管，这里是兜底。

## 4. 角色卡与模型

模型配置写在**活跃角色卡**上（卡里有 `chat_provider` / `chat_model`）。切换角色卡会同时切换模型/温度/top_p/历史条数；每个聊天还可以在「记忆」页单独绑定角色卡。

如果只改「模型」页而不改卡，保存时会同步写活跃卡，避免「设置页显示已改、实际请求还用旧模型」。

## 5. 用量统计

「用量」页：

| 指标 | 口径 |
|---|---|
| 今日调用 | 成功次数 / 失败次数 |
| 今日消费 | 按内置价目估算；失败调用不计费 |
| 今日 tokens | 提示 + 补全；只统计成功调用 |
| 缓存命中率 | 只统计成功调用；命中 tokens / 总 tokens |
| 近 30 天 tokens | 成功调用累计 |
| 近 30 天失败 | 400/401/5xx/网络等 |
| 近 7 天折线 | 调用量；排除失败行 |
| 按模型 | 调用数（含成功/失败）、tokens、缓存、平均回复耗时 |

说明：

- 消费是**估算参考**，不是平台账单；价格来自内置价目表，平台调价或自定义模型可能不准。
- 没有内置价目的模型不计入消费/预算，但调用次数和 tokens 仍会记录。
- 请求失败时不再用请求体估算 tokens，也不会把失败计入缓存命中率或每日预算。
- 「查询平台余额」支持 DeepSeek / Moonshot / SiliconFlow 等适配；不是所有服务商都支持。

## 6. 每日消费预算

「设置 → 对话行为与跨聊天记忆 → 每日消费预算」：

- 开关默认关；开启后填「每日上限（元）」。
- 按内置价目估算今日消费；达到上限当天不再调用模型。
- 超限时仍会清红圈，避免未读滞留循环；第二天自动恢复。
- 预算是「估算闸」，不是平台硬限额；没有价目的模型不参与计算。

## 7. 切换模型的建议

- 日常聊天：便宜、快的模型；有视觉能力的模型才能读图。
- 长文档/任务：上下文更大的模型，同时调高上下文预算。
- 推理模型：回复长度上限要留足思考 token；否则可能出空回复。
- 多聊天不同人设：用角色卡绑定，不必全局切换。

## 8. 常见问题

| 现象 | 处理 |
|---|---|
| 401 | Key 错/过期/与 Base URL 不匹配；重新测试连接 |
| 400 `maximum context length` | 调低上下文预算或减少附件/历史；换大上下文模型 |
| 400 `reasoning_content` | 推理模型的工具往返协议问题；升级到当前版本；仍出现就附日志提 issue |
| 429 | 频率限制；等一会儿/换模型/降低主动发起频率 |
| 消费显示 0 或很低 | 模型没有内置价目，或当天没有成功调用；看 tokens/调用数 |
| 缓存命中率低 | 历史/提示词频繁变化（如状态层、触发器清单、群聊批次）；属正常波动 |
| 预算到了但还想用 | 临时调高上限或关闭预算；第二天自动恢复 |
