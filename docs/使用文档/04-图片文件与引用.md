# 04 图片、文件与引用

本章解决：对方发图片、文件、引用消息时小漓怎么处理，以及文件接收目录怎么配。

## 1. 图片消息

- **单图**：直接发一张图片，小漓会用视觉模型描述/回应。
- **多图**：一次发多张，全部图片按发送顺序放进同一次模型调用，不再只认最新一张。
- **图 + 文字**：图片和文字一起进同一次调用；如果判定为任务，全部图片随任务投递。
- **表情/视频**：视觉通道无法区分视频、表情、图片，统一按图片处理。表情包点击不弹查看器，按媒体矩形裁剪当前帧识别。
- **纯图无文字**：走角色化回复；识别失败会回一句友好提示，不会静默留红圈。

图片来自截图裁剪，不是原图文件；清晰度受微信窗口渲染影响。图片里的文字可能被 OCR 读到，但模型主要看图。

## 2. 文件消息

使用前先在「设置 → 文件目录 → 微信接收目录」选择微信实际的文件接收目录（电脑版微信「设置 → 文件管理」可查看）。

两种用法：

1. **文件 + 指令**：先发文件，紧接着发一句「根据这个文档做一个网站」「总结这份表格」等。小漓会把文件正文提取出来交给模型。
2. **只发文件**：小漓回复「文件已收到～请告诉我需要怎么处理呢？」，并记住这个发送者/文件；之后同一发送者发文字指令时自动关联。

支持提取正文的常见格式：

- 纯文本：`.txt`、`.md`、`.csv`、`.json`、`.html`、`.py`、`.js`、`.ts`、`.xml`、`.yaml/.yml`、`.log`、`.ini/.cfg` 等。
- Office：`.docx`、`.xlsx`、`.pptx`；`.doc/.xls/.ppt` 需要本机安装 Office（走 COM 提取）。
- PDF：`.pdf`（有文本层的 PDF；扫描件没有文本层时提取为空）。

文件按**显示名**在接收目录里查找；重名时取序号最大的那份。微信下载落盘有延迟，小漓会等一拍再找一次；仍找不到就提示「文件下载失败，请重试～」。

## 3. 引用消息

对方「引用」一条消息发来时：

- **引用文字**：引用内容带 `[引用 …]` 标注进模型，模型能看到被引用的原文。
- **引用图片**：自动点击引用区缩略图打开查看器，捕获原图随文字一起识别。
- **引用文件**：按显示名在接收目录定位，走普通文件流程；找不到（例如引用的是小漓自己发的文件）就回落到文字，引用标注里仍有文件名。

引用判据是「气泡面板 + 面板下方左缘竖线」，深色/浅色主题各有一套标定。

## 4. 媒体防抖

对方发图片/文件后，经常会紧跟一段文字说明。小漓会等一等再处理，避免把「图片」和「文字指令」拆成两次：

- **固定等待**：固定等待设定秒数（默认 10 秒）。简单可靠，但对方没跟文字时会白等。
- **智能静默**：纯像素检测对方是否还在连发；连续若干秒没有新消息块就继续，通常更快。硬上限 12 秒。

在「设置 → 对话行为与跨聊天记忆 → 媒体消息等待」切换。

## 5. 文件与任务

- 文件被判定为任务时，文件本体（以及同时发来的图片）会复制进任务目录，交给天枢处理。
- 任务成果文件回传后归档到任务目录的 `sent/`。
- 非任务文件只提取正文给模型看，不会修改原文件。

## 6. 限制与注意事项

- 文件必须已经下载到「微信接收目录」；云盘/未下载完的文件找不到。
- 非 @ 的群文件只记文件名，不提取正文（见 [05 群聊三模式](05-群聊三模式.md)）。
- 图片/文件识别依赖微信窗口可见；最小化时视觉通道是盲的。
- 引用图片需要缩略图能被点击到；滚动出消息区的引用读不到。
- 发送文件（AI 主动发文件）只允许任务工作目录内的文件，见 [12 表情包与图片文件发送](12-表情包与图片文件发送.md)。

## 7. 常见问题

| 现象 | 处理 |
|---|---|
| 图片识别失败 | 确认图片在消息区可见；重发一次；看运行日志 |
| 文件下载失败 | 检查微信接收目录；确认文件已下载；重发文件 |
| 文件内容提取为空 | 扫描版 PDF 没有文本层；加密 Office 文件无法提取；可换格式 |
| 引用图片没识别 | 缩略图可能太小/被滚动出视口；重发原图 |
| 文件+指令被拆开 | 把「媒体消息等待」调成固定等待或增大秒数 |
