# 02 控制面板与引擎

本章解决：认识控制面板、管理引擎的初始化/启动/暂停/恢复、看运行日志、使用托盘。

## 1. 界面结构

左侧导航：

| 页面 | 用途 |
|---|---|
| 首页 | 引擎主控、环境检查、运行日志、触发器概览、版本与更新 |
| 任务 | 任务桥的任务流转与成果归档 |
| 角色卡 | 新建/编辑/复制/导入/激活角色卡 |
| 模型 | Provider 路由表、当前模型、上下文与回复上限 |
| 用量 | 调用次数、tokens、缓存命中、估算消费、余额、每日预算 |
| 记忆 | 每个聊天的近期/重要/索引/深层记忆，注入、编辑、删除、导出 |
| 状态 | 小漓状态层（时段/热度/情绪）可视化 |
| 日志 | 前端运行日志、导出诊断包 |
| 设置 | 全部功能开关与参数 |

右上角是窗口控制按钮；关闭窗口默认隐藏到托盘，不会退出进程。

## 2. 首页

### 主控卡

- **电源按钮**：根据状态执行「初始化引擎」→「启动 bot」→「暂停」→「恢复」。
- **引擎状态**：尚未初始化 / 正在初始化 / 已就绪 / 运行中 / 已暂停 / 初始化失败。
- **监听方式**：未读红圈驱动，红圈几何链路零 OCR。
- **活跃触发器**：当前启用中的定时提醒 + 进行中的状态监视数量。
- **启动策略**：显示「启动即暂停」或「启动即运行」（由 `start_paused` 决定）。

初始化会定位微信窗口并开始截图监听，耗时几秒到十几秒。初始化期间不要操作鼠标、不要切换微信窗口，否则可能读到错误画面。

### 环境检查卡

| 卡片 | 检查内容 | 不通过时 |
|---|---|---|
| 微信 PC 版 | 微信窗口/进程 | 打开并登录微信；不要最小化 |
| 显示缩放 | 当前 DPI 缩放 | 一般只作提示；判据按档位自适应 |
| 天枢 CLI | `rivet` 命令是否可用、是否有天枢窗口 | 任务桥需要；可点「一键安装」 |
| 首轮提示词 | 内置模板或自定义文件 | 可重发一次给天枢 |

每张卡都有「重新检查」；天枢卡在未安装时显示「一键安装」。

### 运行日志

首页底部是 `bot_run.log` 的实时增量（INFO 及以上），只显示用户可读的运行事件。排障用的 DEBUG 全量日志在同目录的 `bot.log`，见 [15 隐私、数据与升级](15-隐私数据与升级.md)。

「清空」只清前端显示，不清磁盘日志。

### 版本卡

显示当前版本、检查更新、一键更新/前往下载。更新会下载安装包、校验大小、拉起安装器并退出当前进程；升级前建议先备份数据。

## 3. 引擎生命周期

小漓把「连接微信」和「开始监听」分成两步：

1. **初始化**：创建 bot、连接微信窗口、加载记忆和角色卡、启动后台线程（触发器/记忆压缩/主动发起调度）。
2. **启动**：主循环开始以 0.5 秒快档轮询红圈、处理消息。

暂停只停止主循环的消息处理；后台调度线程仍在运行，但定时提醒/主动发起的发送也会在主循环节点被暂停消费。恢复后继续。

`start_paused=true` 时，初始化的 bot 处于暂停态；点「启动 bot」才会取消暂停。新装默认启动即暂停，避免刚配置好就自动回复。

## 4. 托盘

托盘图标颜色表示状态：灰=未初始化/就绪，绿=运行中，黄=已暂停，红=异常。

菜单：

- 打开控制面板
- 暂停回复 / 恢复回复
- 退出小漓

关闭主窗口只是隐藏到托盘；要真正退出请用托盘菜单「退出小漓」。

## 5. 本地窗口与远程面板

控制面板默认是本地 pywebview 窗口。开启「设置 → 远程面板」后，同一套页面可以通过手机/平板浏览器访问（局域网 + 访问令牌）。远程模式的页面不显示「当前是远程」以外的差异，但建议只做查看和暂停/恢复，敏感设置回桌面端操作。详见 [13 远程面板](13-远程面板.md)。

## 6. 日志与诊断

- 首页运行日志：实时看回复、任务、错误提示。
- 「日志」页：更完整的 `bot_run.log`，可导出诊断包。
- 诊断包含运行信息、脱敏配置、日志尾部、微信窗口截图；导出后可直接作为 issue 附件，但请先确认没有个人信息。

## 7. 常见操作

| 操作 | 步骤 |
|---|---|
| 暂停自动回复 | 首页主按钮，或托盘「暂停回复」 |
| 恢复 | 首页主按钮，或托盘「恢复回复」 |
| 重新初始化 | 先暂停/退出，再点主按钮；初始化失败时可直接重试 |
| 查看当前版本 | 首页版本卡 |
| 检查更新 | 首页「检查更新」/「一键更新」 |
| 导出诊断 | 「日志」页 →「导出诊断包」 |
| 退出 | 托盘「退出小漓」 |
