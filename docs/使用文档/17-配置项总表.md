# 17 配置项总表

本章是 `config.json` 的速查表，面向高级用户和排障。普通使用优先用设置页——设置页会自动保存并做校验。

> 修改 `config.json` 前请先备份；程序运行中直接改文件可能被设置页/退出时的写盘覆盖。

## 1. 模型与回复

| 键 | 默认 | 说明 |
|---|---|---|
| `ai_api_url` | DeepSeek 兼容地址 | 聊天/视觉共用端点（由 Provider 投影） |
| `ai_api_key` | 空 | 聊天 Key（DPAPI 加密落盘） |
| `vision_api_url` / `vision_api_key` | 跟随聊天 | 旧字段；单模型化后一般不用 |
| `chat_model` | `deepseek:deepseek-flash` | 当前模型（由活跃卡投影） |
| `chat_temperature` | 0.7 | 温度 |
| `chat_top_p` | 0.9 | top_p |
| `max_history` | 1000 | 单聊天最大历史条数 |
| `max_context_tokens` | 100000 | 单次请求上下文预算，超限裁最旧历史 |
| `reply_max_tokens` | 40000 | 回复长度物理上限（含思考 token） |
| `cooldown` | 3 | 两次回复之间的冷却秒数 |
| `api_retry` | 2 | 429/5xx/网络重试次数 |
| `api_timeout` | 60 | 单次请求超时秒数 |
| `api_wall_budget` | 45 | 单次调用重试总时长封顶 |
| `start_paused` | true | 启动后是否先暂停（下次启动生效） |
| `providers` | 预设列表 | Provider 路由表（`id/name/base_url/api_key/models`） |
| `chat_card_bindings` | 空 | 聊天 → 角色卡 id |
| `chat_card_params` | 派生 | 绑定卡的运行时参数投影（落盘剥离） |

## 12. 热生效说明

- 设置页保存的开关/数值一般热生效（写 cfg + 写运行中 bot 属性）。
- `start_paused` 只影响下一次启动。
- `memory_file`、`tasks_dir` 等路径类改动建议重启引擎。
- `providers` 保存后会重投影并热切换当前模型。
- `remote_*` 改动会重启远程面板服务。
- 手工改 `config.json` 后需要重启小漓（设置页不会自动感知文件变化）。
