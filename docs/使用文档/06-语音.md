# 06 语音

本章解决：小漓怎么读对方语音、怎么发微信语音条、需要哪些前置条件。

## 1. 收语音

微信不开放语音消息的读取接口，小漓靠视觉通道读消息。**对方发来的语音必须先转成文字**，否则小漓读不到内容。

在电脑版微信「设置 → 通用」里开启**语音自动转文字**。开启后，语音消息下方会出现转写文字，小漓按普通文字消息处理。

## 2. 发语音：音源接口化

小漓不内置语音模型，而是接你自己部署的 TTS 服务（例如 GPT-SoVITS 的 `api_v2` 接口）。

需要准备：

1. 一个可访问的 TTS 端点，例如 `http://127.0.0.1:9880/tts`。
2. 一个音色档案：档案里有「通用」参考音频（必填），以及可选的情绪参考（开心/难过/生气等）。
3. 虚拟声卡：例如 VB-CABLE。微信没有语音发送接口，小漓走「把默认录音设备切到虚拟声卡 → 模拟按键触发录音 → 把 TTS 音频写进声卡 → 检测绿色胶囊确认已触发」的链路。

参考音频路径是 **TTS 服务器上的路径**，不是小漓本机的路径；各人部署环境不同，所以出厂不带任何音色。

## 3. 设置步骤

「设置 → 语音发送」：

1. 填「TTS 端点」。
2. 选「音色档案」→「新建」，填档案名称；「通用」参考音频和参考文本稿必填。
3. 需要情绪时，点「添加情绪参考」，填情绪名、参考音频路径、参考文本稿。
4. 勾选「当前使用此档案」。
5. 点「语音自检」：用「通用」参考合成一句问候；能播放说明 TTS 链路通。
6. 选「发送模式」：
   - **关闭**：不声明语音工具，只发文字。
   - **模型自主**：模型按语境决定是否调用 `send_voice`。
   - **始终语音**：每条回复都必须经 `send_voice` 发出（工具是强制回复通道）。

## 4. 发送链路与回退

发送语音时，小漓会：

1. 调 TTS 合成音频（受「合成超时」限制）。
2. 临时把系统默认录音设备切到虚拟声卡。
3. 在微信输入框触发录音，把音频写进声卡。
4. 检测绿色语音胶囊确认已触发。
5. 结束后恢复原录音设备。

任一步不确认（设备没找到、胶囊没出现、合成失败、超时）都会**自动回退文本**，回复不会丢。

## 5. 参数

| 设置 | 默认 | 说明 |
|---|---|---|
| 发送模式 | 关闭 | 关闭 / 模型自主 / 始终语音 |
| 单段语音上限 | 55 秒 | 超过会拆分或回退文本 |
| 合成超时 | 120 秒 | TTS 服务慢时调大 |
| TTS 端点 | 空 | GPT-SoVITS api_v2 兼容地址 |
| 音色档案 | 空 | 「通用」参考必填；其余是情绪 |

「始终语音」且 TTS 配置齐全时，`send_message` 不再声明；配置不齐时保留 `send_message` 作为回退通道，避免一句话都发不出去。

## 6. 常见问题

| 现象 | 处理 |
|---|---|
| 对方语音小漓没反应 | 微信没开「语音自动转文字」；开启后重发 |
| 语音自检失败 | 检查 TTS 端点、参考音频路径、TTS 服务日志 |
| 合成成功但微信没发 | 检查 VB-CABLE 是否安装、默认录音设备是否可切换、微信窗口是否可见 |
| 发出去是文字不是语音 | 任一环节未确认，已自动回退；看运行日志里的「语音」行 |
| 「始终语音」下模型只回文字 | TTS 配置不齐时这是预期回退；补齐端点/档案后重启引擎 |

> 语音发送对设备名、窗口位置、输入框可聚焦比较敏感；运行期间不要切换微信窗口或改系统录音设备。
