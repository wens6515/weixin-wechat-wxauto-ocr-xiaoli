# 更新记录 v2.1.4（2026-08-24）

> 默认角色卡人设升级为完整角色档案，聊天回复按空行拆分发送——长段落回复拆成多条消息更贴近对话节奏，重设人设让模型沉浸更深入。

## 核心修复

- **默认角色卡人设升级**——`CARD_TEMPLATE["system_prompt"]` 从旧的「DeepSeek 蓝色大肥鱼」六行简介（392 字）换成完整角色档案（1316 字）：从「一、基础人设档案」（姓名/原型/种族/气质标签/核心信念）到「二、穿搭风格设定」「三、行为习惯与小癖好」「四、身世与内核设定」，并新增【角色沉浸要求】五条规则（含"以角色第一人称思考""不要用括号包裹的内心活动""不用 emoji、用颜文字"等）。其余字段（id/name/emoji/nickname/chat_provider/chat_model/temperature/top_p/max_history）不动。
  - 影响路径：新装首次生成默认卡、旧配置迁移建卡（migrate_config）都走这份模板——旧用户升级后新卡也会拿到新档案人设。
- **回复按空行拆分发送**——`_send_text` 在聊天回复含"至少一个空行"时，拆成多条消息分别发送（兼容 `\n\n`、空行带空格、连续多空行，空段丢弃）；不含空行的回复保持单条（行为零条）；"正在处理"占位消息永不拆分、计数语义不变；占位归零只执行一次（幂等）。
  - 影响路径：纯文字、图片识别、任务桥占位全部汇经 `_send_text`——拆分只影响发送条数，不影响对话记忆（记忆在调用侧先存入）。
