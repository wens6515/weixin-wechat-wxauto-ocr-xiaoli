# v3.0.1「缓存命中工程 · 语音自检 · 任务页」更新记录

> 一句话主线：围绕**会话成本**做缓存命中工程——近期记忆改**阶梯滚动**、重要记忆挪到**尾区**，让 API 前缀缓存全程命中；语音配置新增**就绪状态灯**与**自检试听**；界面新增**任务页**；文件判据收敛到纯视觉。

## 缓存命中：近期记忆阶梯滚动

- 旧行为的问题：近期窗口**逐条滚动**，每轮把最旧一条从头弹出——注入序列每轮都在变，API 前缀缓存从第一条历史就失效，长会话每轮按全价计费
- 新行为：窗口在 `[保留条数, 保留条数 + 滚动步长]` 之间波动，攒到上限把溢出段**按序一次性弹出**归档——两次滚动之间注入序列是纯追加，前缀缓存全程命中
- 步长 `memory_rolling_step` 默认 30（普通聊天每条很短，逐条滚动把上下文切得太碎），记忆页可调；设 0 即退回逐条滚动旧行为
- 验证方式：跑几天后看用量页**缓存命中率**是否抬升

## 缓存命中：重要记忆挪到尾区

- 重要记忆的 system 注入从「人设后、历史前」挪到「历史后」（与相关记忆同区），普通对话链路与图片理解链路同步调整
- 效果：每次记忆压缩提交新条目，都不再打碎「人设 + 历史」这段前缀——此前重要记忆一动，整个前缀缓存随之作废

## 语音：就绪状态灯 + 自检试听

- 修复「通用」音色档案**保存即清空**：界面收集逻辑把禁用态的情绪名当成整行跳过，路径与文本稿输入框从未被收集；保存后档案丢失，连带「始终语音」不生效
- 语音卡新增**就绪状态**灯：TTS 端点 + 激活档案 + 通用参考齐全即亮（纯本地判定），配置齐没齐一眼可见
- 新增**语音自检**按钮：真实合成一句「你好呀，我是小漓！」回传前端试听；失败时给出明确原因（端点不通 / 档案缺失 / 合成报错）——接入的语音模型能不能用，一试便知

## 文件判据：只认视觉层

- 删除 OCR 扩展名旁路与相关的恒等死分支，**文件卡片唯一判据 = 视觉层 `type=FILE`**（面板色 + 实心小图标），与 v3.0.0 的头像锚定同一哲学：不降级、不做文本猜测
- 附带修复：正文里含「.docx」等字样的**纯文字消息**不再被误判成文件、回「文件下载失败」

## 模型参数可调

- **回复长度上限**统一为 `reply_max_tokens`（单键，含推理模型的思考 token，默认 400；思考模型建议 1000+），模型页「当前对话模型」卡可调；旧配置里的 `vision_max_tokens` 首次启动自动改名迁移，值不丢
- **上下文预算** `max_context_tokens` 可配置（默认 100000），模型页同位置

## 用量页三项校准

- **估算与实测拆开**：本地估算行带「≈」角标，折线图只画实测调用——此前估算行混在实测里，用量页看着「非常不准」
- **图片成本修正**：估算兜底路径的图片按固定 1000 token 占位——原先按 base64 字符数折算，高出真实成本数倍
- **耗时口径修正**：成功调用的 latency 只计成功那次尝试的净耗时（重试的退避等待不再计入），失败调用保留全程耗时

## 任务页

- 导航新增「任务」：**天枢处理中 / 待回传 / 已归档**三计数 + 全量任务列表 + 二次确认删除（任务名做路径逃逸校验）
- 与命令行共用同一套任务状态扫描，界面看到的就是实际状态

## 升级注意

- 配置无破坏性变更，覆盖安装即可；对话记忆、任务目录、定时提醒与触发器、角色卡、用量统计都不受影响
- `vision_max_tokens` → `reply_max_tokens` 为一次性自动迁移：首次启动读旧值改名写回，无需手动处理
- 新增三个可调参数不配置则用默认值：滚动步长 30 / 回复长度 400 / 上下文预算 100000

## 工程

- **三大源码拆分**（行为零变化，为后续维护减负）：`wx_backend/visual_backend.py` 拆出 win32 / vision / badge / regions / voice_channel 五模块；`xiaoli_bot.py` 拆出 task_bridge（任务桥纯函数）/ bot_daemons（三后台线程）/ selftest；`wechat_bot.py` 拆出 file_text（文件文本提取）/ media_capture（媒体捕获 Mixin）——全部走门面 re-export，对外导入路径零变化
- 新增 **pyflakes 静态回归闸**：扫描全部源码断言无 undefined name，堵住「测试盲区里的名字丢失」这类拆分事故
