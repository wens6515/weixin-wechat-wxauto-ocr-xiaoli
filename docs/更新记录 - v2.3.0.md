# 更新记录 v2.3.0

> 监听与回复全面提速（0.5s 恒定快档 + OCR 两段化，首条消息端到端 16~20 秒 → 约 6~9 秒）、API 韧性（指数退避 + 角色内友好报错）、用量统计页、定时消息（聊天里一句话创建）、微信窗口初始化自动定位。定位/监听参数全部来自真机实测基准（`tools/poll_benchmark.py` 可复现）。

## 核心升级

- **不间断快档监听**——引擎/控制台轮询恒定 0.5s（原 2s）：每轮只做后台静默截图 + 红圈像素检测，无红圈零 OCR 零点击零前台抢占，真机实测约占单核 8~12%（10 核口径总 CPU ~1%）。砍掉「空闲慢档」——用户定调响应优先，监听永不休息。
- **OCR 两段化提速**——检测到红圈先裁会话行条带 OCR 锚定会话名（替代 1.2s 整表 OCR），切会话后标题带+消息区**联合裁剪 2x OCR 一次读完**（事件内 OCR 从最多 6 次封顶到 2 次，下边框钉在标定消息区下沿、输入框不入镜）；选中态用固定色 (13,168,105) 像素判定防 toggle 误点；`get_messages(assume_switched)` 复用切换结果省一次点击两次 OCR；处理失败 8s 退避防滞留红圈打满单核。
- **API 韧性**——chat/vision 共用统一调用入口：429/5xx/网络异常指数退避（1s→2s→4s 封顶 8s）、尊重 Retry-After（超 15s 放弃）、墙钟预算 45s 封顶（根治「超时×重试叠成分钟级等待」）、4xx 不重试；重试耗尽返回**角色内友好文案**（不写历史），「API 错误: 503」这类原文从此不会发给好友。
- **用量统计**——每次模型调用终态记一条 JSONL（tokens/耗时/成败，重试多次只计一条）；导航「任务」位改为**用量页**（今日/近 30 天/按模型/近 7 天，数字列居中），任务桥表格并入设置页。
- **定时消息**——聊天里说「明天下午 3 点提醒我查成绩」即可创建（vision 调用新增 `set_reminder` 工具，模型按注入的当前时间换算相对表达）；系统时间单轨 + 5 分钟补发宽限 + 每天/每周滚动；闹钟线程只算时间入队、主循环节点消费（旁路占位计数直发，不破坏 skip_bot 语义）；设置页「定时消息」组可视管理。
- **微信窗口初始化自动定位**——连接成功即把微信窗口摆到主屏**工作区**右半边（SPI_GETWORKAREA：自动隐藏任务栏打满不留缝、固定任务栏自动扣减、左右任务栏自适应；按「可见内容」语义外扩 DWM 不可见边框，与手动拖到打满的系统行为一致），并告知用户勿动；最大化/最小化先还原再定位；运行期最小化哨兵自动恢复 + 截图尺寸骤缩第二道防线（最小化态视觉通道是盲的，真机实测静默漏消息）。配置 `wechat_window_rect` 可自定义或 `off` 关闭。
- **设置页重构**——分组锚点目录横排置顶（芯片式，点击滚动定位、滚动高亮同步），任务桥/定时消息分组内嵌；滑杆/步进框/下拉框**滚轮误触根治**（无焦点透传页面滚动，下拉框一律不响应滚轮）；表头透明化圆角化（所有表格尖角消失）。

## 修复

- **会话身份以标题区为准**——列表条带 OCR 漏字产生的残缺名（真机「强盗”集」）不再落进记忆；标题解析的权威名统一用于记忆/回复/日志。
- **memory 键归一化**——剥掉所有引号变体与空格再存取，`强盗”集团`/`"强盗"集团`/`" 强盗 " 集团` 同一会话不再分裂。
- **单换行也分次发送**——拆分规则从「空行」放宽到「任意换行」，模型用单 `\n` 分句时不再整段一起发。
- **活跃角色卡缺失自动补建**——重置测试区后启动不再反复告警「活跃角色卡不存在」。
- **联合 OCR 标题带钉在标定标题区下沿**——标题区与消息区夹缝内容（真机「何镇鸿:[图片]」）不再污染标题串。
- **首页环境检查自动执行**——启动即检，不再永远「检测中…」。

## 已知边界

- 多显示器用户初始化会定位到**主屏**右半边（设计使然，副屏需求走 `wechat_window_rect` 自定义或 `off`）。
- 带图/文件消息因 10 秒防抖等待，回复仍需多等一轮。
- 处理失败的会话 8 秒退避期内暂不重试（防打满单核），期间新消息顺延处理。
- 历史摘要/世界书、文件追问缓存规划于后续版本。
