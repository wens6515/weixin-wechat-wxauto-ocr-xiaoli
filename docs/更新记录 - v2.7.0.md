# v2.7.0「按聊天绑定角色卡」更新记录

## 新增

### 按聊天绑定角色卡

- 记忆页选中任意聊天 → 点「绑定角色卡…」→ 选一张卡：该聊天的**人设、模型、温度、端点**全部以所绑卡为准（私聊用 A 人设、工作群用 B 人设互不干扰）；选「跟随全局活跃卡」即解除绑定
- 未绑定的聊天跟随全局活跃卡，行为与旧版完全一致；聊天列表对已绑定的聊天带 🎭 标注
- 绑定键与小漓的会话记忆键同一归一化口径——OCR 把聊天名读出引号/空格差异时不会分裂成两个绑定
- 绑定、换绑、编辑卡内容**即时生效**，无需重启；触发器回递、文件识别等走对话链路的场景自动跟随绑定
- 微信昵称（@ 唤醒名）保持全局——那是微信号本身，不随卡变
- 被绑定的角色卡被删除时，该聊天自动回落全局活跃卡，不会报错

### 首页更新检查

- 首页新增「检查更新」按钮：对比 GitHub 最新 Release 与内置版本号，有新版本时显示「发现新版本 vX.Y.Z」+「前往下载」直达下载页（覆盖安装即可升级）
- 启动时后台静默查一次，网络不通保持安静不打扰；手动检查失败会给出原因
- 不做自动下载安装——提示 + 跳转浏览器，升级由用户自己掌控

### PDF 文字提取

- 直接发 PDF 让小漓读内容不再回复「这个格式我看不懂呢～」：pypdf 读取文字层（纯 Python，零系统依赖）
- 扫描件/图片型 PDF 没有文字层，仍会提示格式不支持（这类文件建议直接派任务给天枢）

## 优化

- **微信文件目录保存即时生效**：设置页修改微信文件接收目录后推送给运行中的小漓，不再需要重启
- **工程拆分**：wechat_bot.py 拆出记忆系统（`xiaoli_app/memory_store.py`）与 LLM API 客户端（`xiaoli_app/llm_client.py`），主文件 2595 → 2074 行；对外行为与接口完全不变
- **OCR 引擎升级评估留档**：`docs/OCR引擎升级评估.md`——新版 PP-OCRv6 识别更好但事件路径慢约五成，本轮暂缓升级，文档附复测步骤
- 清理群聊发送者名相关的过时注释（该功能早已实现，注释还在说「待实现」）

## 升级注意

- 本次起程序内置版本号常量（`xiaoli_app/version.py`），更新检查依赖它；后续发版记得同步修改
- 配置文件无破坏性变更，覆盖安装即可；`chat_card_bindings`（按聊天绑定）为空时行为与 2.6.2 完全一致
- 如果用过「一键删除归档」等功能，任务归档数据不受本次升级影响

## 安装

下载 `xiaoli-setup-v2.7.0.exe` 双击覆盖安装（免管理员权限），配置与记忆自动保留。
