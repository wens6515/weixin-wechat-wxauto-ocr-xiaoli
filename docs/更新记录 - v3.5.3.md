# 更新记录 · v3.5.3「会话定位修复 · 设置页分组 · 工具化回复 · 状态层」

> [!WARNING]
> 本版修复了主动发起/追尾「切到错误群聊」的会话定位缺陷，重做设置页导航，新增可选的严格工具化回复，并改写状态层注入与状态页。工具化回复**默认兼容模式**（保持旧行为）；严格模式可在「设置 → 对话行为」手动开启，建议先观察模型遵从率。遇问题请到 [Issues](https://github.com/wens6515/weixin-wechat-wxauto-ocr-xiaoli/issues) 提交（附日志与复现步骤）；需要旧行为可回退 v3.5.2。

## 会话定位修复（重要）

真机缺陷：主动发起/追尾要切到私聊「联系人甲」时，列表里「某群聊」那一行的预览恰好是「联系人甲：yes, is me」——旧实现把列表 OCR 的**每一行**都当候选做子串匹配，预览行先命中，点击落进群里；随后标题复验不过，每次都放弃发送，窗口还被拽到群里。

修复口径：

- 列表区只认「每个会话行的标题行」：按 y 聚类 + 只取主名行，预览行、标签行、时间戳不再进入候选。整表提名与按名定位共用同一套聚类函数，杜绝两套口径漂移。
- 匹配分三档并按档收敛：归一化完全相等 > 候选是目标的 OCR 截断 > 候选以目标开头；档内出现多个候选即 fail-closed，不点（同名联系人与群、名字互为前缀都不再赌）。
- 点击后立刻用标题复验：标题非空且不是目标会话 → 不更新 `_current_chat`、返回 False；标题读不到（遮挡）才保持旧语义信任点击。
- 定位阶段 DEBUG 记录命中档位，失败时 WARNING 带候选清单，便于真机排障。

## 设置页：分组目录 + 搜索

- 17 个设置卡片按 5 组收拢：外观与身份 / 对话与记忆 / 自动化 / 能力 / 系统；左侧目录吸顶，右侧只显示当前组。
- 组内宽屏两列（CSS 多列瀑布流，短卡自动往上补），窄屏回落单列；手机远程面板同样受益。
- 顶部搜索框跨组过滤设置卡片，显示命中数量，Esc / 清空回到上次分组。
- 记住上次打开的分组（localStorage）；`#sec-*` 深链自动切到所属分组并滚动定位。
- 所有卡片 `id` 保留，旧锚点/文档链接不失效。

## 工具化回复（默认兼容，可切严格）

- 新增设置「设置 → 对话行为 → 工具化回复」：`strict` 严格模式 / `compat` 兼容模式（默认）。
- 严格模式下，模型对外动作只能经工具：文字走 `send_message`、语音走 `send_voice`、表情包/图片/文件走对应发送工具；直接输出的文字只当草稿丢弃。
- 模型只输出文字、没调工具时，默认再提示一次「必须调用 send_message」重试（同一设置页可关）；纠偏轮的 assistant 会回传 `reasoning_content`，修复 thinking 模型 400。
- 群聊全接收（`auto`、无 @ 的 `hybrid`）始终只认发送工具；`hybrid` 的 @ 批次在严格模式下同样必须调工具，引擎不兜底发文本。
- 主动发起/追尾/触发器回递统一走同一套闸门：严格模式下没调发送工具 = 不发。
- 成本：严格模式下一次响应只调 `send_message` 且成功时直接收尾，不再多请求一轮；表情/图片/文件仍允许下一轮补话。

## 状态层与状态页

- 注入文本从「描述性背景」改为「状态 → 本轮行为」：时段 / 真实当日消息数 / 心情 / 精力 / 起因 + 2~3 条可执行约束，并明确不覆盖回复纪律。
- 注入位置移到所有可选 system 块（触发器清单 / 表情包清单 / 语音纪律 / 工具纪律）之后、当前消息之前——真正紧贴决策点。
- 状态没变化只注入一行短标记；精力本地衰减（每 30 分钟 -4，下限 20）；当日热度用会话计数器，不再被近期窗口 30~60 条封顶。
- 定量输出改为固定 mood 枚举 + `trigger` 一句起因 + 最近 30 条历史。
- 「状态」页改版：顶部概览（时段 / 整体精力 / 今日活跃聊天数），每个聊天一张卡（情绪标签、精力条、今日条数、情绪起因、最近状态趋势），底部「状态怎么影响回复」说明。

## 3.6.0 预告

下一个版本会把「模型能做什么」从聊天与提醒扩展到**能管钱、能管设置**：在用户授权与额度内，模型可以自主支配一笔可配置的零花钱（下单/买礼物/发红包等），并把结果回传；管理类操作（开关功能、查询用量与状态、调整设置）也将工具化。资金操作同样是一种工具调用，默认每次支出都需要确认，敏感操作不开放给模型。具体范围以实际发布为准。

## 升级方式

覆盖安装即可，`config.json`、`cards/`、`memory.json`、`memory_global.json`、`memory_deep/`、`persona_state.json`、`chat_meta.json`、`usage.db` 保留。`tool_reply_mode` 缺省为 `compat`；想试严格模式到「设置 → 对话行为」切换。
