# v3.1.0「工具按开关注入 · 触发器可管理 · 表情包」更新记录

> 一句话主线：把「工具能不能用」从任务桥总闸里拆出来，**每个工具按自己的开关
> 单独注入**；触发器从「只能建」升级为「模型可查询 / 取消 / 修改」；新增**表情
> 包发送**（内置默认表情包库）；回复分段节奏可调。

## 工具按开关单独注入（修任务桥总闸事故）

- 修实测事故：任务桥关闭时，文字消息的**闹钟 / 语音 / 联网搜索 / 记忆检索全部
  失效**——旧逻辑用任务桥总闸把守整条工具链路，总闸一关模型手里就一个工具都
  没有，只会闲聊（「明天 9:30 提醒我洗被子」被当闲聊敷衍）
- 新语义：**开关只决定各自工具是否注入**——任务桥管 `dispatch_task`、语音模式
  管 `send_voice`、联网开关管搜索双件套、深层记忆管 `recall_memory`，定时提醒
  恒可用；文字消息与图片+文字消息恒走 vision 工具链路（调用失败仍降级普通聊天）
- 提示词三变体：任务桥开提投递、关但其他工具可用用中性变体、一个工具都没有
  才用「不要调用任何工具」防幻觉（那句硬话会把已声明的工具一起压制）
- vision 链路补 `top_p`（文本回复恒走该链路后不能静默失效）；工具集为空时请求
  不带 `tools`/`tool_choice` 键（防部分厂商对空数组返回 400）

## 触发器可管理：模型能取消 / 修改 / 查询

- 新工具 `manage_reminder`：AI 现在能办「把闹钟改到十点」「取消雨停监控」
  「我有哪些约定来着」——之前只能创建，改和删全靠设置页手动
- 三种模式（设置页「定时与监视」可选，默认关闭）：
  - **关闭**：模型只能创建（现状）
  - **仅工具**：AI 被问到时先查询拿到编号再操作
  - **清单注入**：进行中的触发器随每次请求告知 AI——直接一步操作，AI 还能
    主动说出「明天 9:30 我会叫你」
- 安全边界：只能操作**当前聊天**的触发器；已触发 / 过期 / 失效的不能动；
  改监控网页必须取消重建（改了 URL 等于没看过页面）；修改结果即时生效
  （轮询间隔、截止时间、关键词都可改）

## 表情包：AI 会斗图了

- 新工具 `send_sticker`：AI 可以**只回一张表情包**，也可以**表情包 + 文字**
  一起回（表情先发）；发送走剪贴板粘贴（GIF 按动图发出），失败自动放弃、
  绝不为一张图回退文字刷屏
- 内置 **29 张默认表情包**（安装目录「表情包」文件夹，往里加图即可扩充）；
  新图用文件名当描述即刻可用，点「AI 优化标签」让 AI 逐张看图写描述与关键词
- 三种模式（设置页「表情包」可选，默认关闭）：
  - **清单注入**：每次请求带上全部表情包目录，AI 零额外往返直接挑（库小省事；
    可用「预览注入清单」看到注入原文与 token 估算再决定）
  - **按需查询**：AI 想发时自己选——搜关键词拿相关候选，或直接拿完整清单
    慢慢挑（库大更省 token）
- **表情包管理**弹窗：缩略图一览、单张改描述 / 标签、添加图片 / 文件夹、
  打开库目录、AI 打标进度条实时可见

## 回复节奏可调

- 设置页新增「回复节奏」：**段间等待**（多段回复时下一段停留固定秒数，默认 2s
  不变）与**间隔抖动**（每段在上下限内随机，更像真人打字）两个开关，互斥、
  也可都关，保存即热生效

## 修复

- **用量页折线图**：近 7 天调用量七天全零贴底不动——SQLite 迁移后时间戳是
  epoch 数值，折线图还在按字符串切片取日期键，永远对不上；改走统一日期格式化，
  并补回归测试
- **主题重启回退**：换任何主题重启都变回「深海小漓」——启动链路从未应用保存
  的主题（界面默认值是深海小漓，配置本身一直存得是对的）；现在启动即恢复
  上次选择
- 设置页导航补上「回复节奏 / 表情包」锚点；设置页滚动越过导航后右下角出现
  **回到顶部**圆形按钮

## 升级注意

- 配置无破坏性变更，覆盖安装即可；对话记忆、任务目录、触发器、角色卡、用量
  统计都不受影响
- 新功能全部**默认关闭或保持默认行为**：触发器管理、表情包在设置页自行开启；
  回复节奏默认与旧版一致（段间 2 秒）
- 新配置键（`model_trigger_manage` / `sticker_mode` / `segment_*` 五键）首次
  启动自动补齐写回，无需手动处理
