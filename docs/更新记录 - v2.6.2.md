# v2.6.2 更新记录 ——「文件定位重构」

## 修复

- **把 bot 发的文件发回来，不再报「文件下载失败」**：找文件方法整体重构——按消息里的文件名直接定位接收目录（同名文件取 (N) 重名编号最大的，即最近下载），删除旧的目录快照与成果登记排除机制（旧规则会把落在 bot 发送后 5 分钟内的回传误杀）
- **OCR 漏读文件名分隔符容错**：文件名里的下划线/连字符常被 OCR 漏读（真机事故：磁盘名「小漓_深海小剧场.html」识别成「小漓深海小剧场.html」导致按名找不到），匹配前对两侧文件名做分隔符归一化
- **图片+文字消息临时图片泄漏**：各处理分支统一清理，不再在系统临时目录残留聊天图片文件
- **历史文件卡片不再被反复识别**：修复窗口边界过滤被绕过的问题（含占位回复挂起场景），bot 自己的文件卡不再被当成对方新消息重复处理
- **文件卡片的类型图标不再被当成图片点击**：文件卡右端的 W/PDF 彩色图标会独立成小媒体块，现在按「与文件名同行」排除，不再被点击、也不再混进任务附件
- **启动自动环境检测生效**：修复首页两处显示事件相互覆盖导致检测从未执行、界面永远「检测中」的问题

## 优化

- **前端日志双轨**：新增 bot_run.log（INFO 事件流：发现消息 / 判断 / 发送），日志页与首页运行日志区改读它；bot.log 继续保留全量 DEBUG 供排障——界面清爽、排障信息不丢
- **任务桥归档管理**：设置页任务桥表格列出全部归档任务（任务 ID / 描述 / 归档时刻），描述与更新时间列换位，新增「删除选中归档」「清空归档」按钮（均有确认，处理中的任务不可删）
- **用量页刷新降载**：每次刷新对用量记录文件的全量读取从三次降为一次

## 升级注意

- 接收目录里的 `file_snapshot.json` 与任务目录里的 `sent_back_stems.json` 已不再使用，可手动删除
- 归档任务删除后不可恢复，清理前请确认不再需要其中的成果文件

## 安装

下载 `xiaoli-setup-v2.6.2.exe` 双击安装（免管理员权限），旧版本可直接覆盖安装，配置、角色卡与记忆自动保留。
