# 下个版本规划：桌宠（预研沉淀）

> 桌宠不在当前更新批次内（当前批次：触发器统一 + 用量统计升级）。本文冻结当前全部已知
> 方法与结论，待当前批次落地后按本文开工，届时无需重新调研。

## 一、目标

小漓关闭主窗口后不再只是托盘图标，而是一只常驻桌面的鲸鱼娘桌宠：状态随引擎事件变化、
气泡播报（含今日 token 与消费）、右键菜单可控，替代/共存于现有托盘方案。

## 二、调研结论

### 1. 哦鲸鲸（D:\AI\哦鲸鲸）

- 本体：DeepSeekWhaleWidget 1.0.1 的 NSIS 安装包（.ndata 段 + COMCTL32 导入特征），
  内部为**闭源 Qt6 应用**——无源码，代码层面不可套用。
- 功能清单（由 userdata.json 反推）：
  - 鲸鱼贴图桌宠：缩放（scale 0.6）、音效开关与音量、气泡开关（bubbleOn）
  - 屏幕锚定（hAnchor/vAnchor 右下）+ 拖拽记忆位置（winPos）
  - 计费账本（usageMode=ledger）：API key 加密存储（AES-GCM，salt/iv/tag），
    轮询官方余额接口，按天记 lastBalance / todayUsage / history（余额差值倒推消费）
- 结论：只能借鉴交互设计。单独运行它与小漓零集成（key、账本、状态各自独立），不采用。

### 2. DeepSeek Harness（DSH）桌宠插件生态（GitHub）

- [deepseek-whale-maid](https://github.com/ll2010650-coder/deepseek-whale-maid)（MIT，最完整）：
  - Electron 43 独立进程桌宠 + 实时计费中心，DSH 插件形态（core/billing/client/desktop/launcher）
  - 透明无边框置顶窗口、跳过任务栏、托盘常驻；断线指数退避重连（1s→30s），Harness 关闭可自愈
  - 18 个引擎状态 → 专属表情/道具/动效；6 形态立绘 × 普通/像素双风格，伪 3D 悬停倾斜
  - 拖拽、位置持久化、多显示器 DPI、边缘吸附、点击穿透（快捷键切换）、25%~150% 缩放、
    透明度、Reduce Motion
  - 悬停气泡显示状态/进度/费用/余额；边界原则「气泡只做摘要，不显示推理过程/大段输出/
    密钥/路径」
  - 计费口径（与本版用量统计升级同构，可直接沿用）：
    - 余额 = GET api.deepseek.com/user/balance；失败保留上次快照显示「刷新失败」，绝不伪造 ¥0
    - Token 五桶：Input / Cache Hit / Cache Miss / Output / Reasoning（reasoning 是 output
      细分，不重复计费）
    - 本地版本化价目（含 effective_date/source），无价格的模型只计 token 不猜钱
- 其他同类（形态相近，未深入）：dsh-whale-musume（盯余额）、DSH 桌宠插件（discussion #2262）、
  大肥鱼桌宠（discussion #3143，调 API 聊天+40 条记忆）、chat-billing（discussion #4295）、
  dsh-whale-pet（GitCode，余额徽章+语音播报）。
- 结论：均为 Electron/JS 的 DSH 插件，代码搬不进 PySide6 项目；但 whale-maid 为 MIT——
  立绘素材与设计口径（状态机、气泡边界、计费诚实边界）可合法借鉴。

## 三、路线对比与定案

| 路线 | 说明 | 结论 |
|---|---|---|
| A. 自研 PySide6 桌宠模块 | 小漓 GUI 进程内新增无边框透明置顶 QWidget + QTimer 帧动画，零新依赖 | **采用** |
| B. 复用 whale-maid Electron 桌宠 | 独立进程 + IPC 转发引擎事件 | 否：为桌宠引入 Node/Electron 运行时（体积+内存），与「仅天枢需要 Node」的形态冲突 |
| C. 单独运行哦鲸鲸 exe | 零开发 | 否：零集成，key/账本/状态全在第三方程序里 |

## 四、实施方案（路线 A）

### 模块与窗口

- 代码位置：xiaoli_app/ui/pet.py（纯 Qt，无后端依赖），main_window 集成挂载
- 窗口特性：FramelessWindowHint + WA_TranslucentBackground + WindowStaysOnTopHint +
  Tool 型窗口（不进任务栏）；QLabel 立绘 + QTimer 帧动画；多显示器按屏幕可用区域定位
- 素材策略：起步用现有 小漓.png + 程序化动效（上下浮动/摇摆/翻面/呼吸缩放），后续可
  替换手绘帧动画或 MIT 立绘；素材放 assets/pet/

### 状态机（接引擎 bus 事件）

| 引擎事件 | 桌宠状态 | 表现 |
|---|---|---|
| running 空闲轮询 | idle 漂浮 | 缓慢上下浮动 |
| 处理消息中（vision/判定调用） | thinking | 歪头/思考动效 |
| 任务投递/天枢运行中 | working | 搬砖动效 + 气泡「任务处理中」 |
| paused | sleeping | 睡觉 Zzz |
| API 最终失败 | sad | 委屈动效 + 气泡 |
| 触发器达成/任务回传 | notify | 气泡播报结果摘要 |

- 气泡播报同类事件节流合并；内容只做摘要，不含密钥/路径/大段输出（沿 whale-maid 边界）。

### 交互

- 拖拽移动 + 位置持久化；边缘吸附（默认避开微信右半屏区域）
- 右键菜单：打开主界面 / 暂停 / 恢复 / 今日用量（token + 估算消费）/ 退出
- 双击互动彩蛋；点击穿透开关（设置项）
- 关闭主窗口行为：设置项三选一「桌宠（默认）/ 托盘 / 直接退出」；单实例互斥语义不变

### 与当前批次的联动

- 气泡「今日用量」依赖用量统计升级（记录层缓存命中/未命中 + 本地价目估算）提供的数据
- 触发器（合并版 set_reminder）达成时的播报经 bus 事件驱动桌宠 notify 状态

## 五、已知风险与前置验证

1. **PrintWindow 遮挡黑图**：后端实测「微信被其他窗口完全遮挡 → PrintWindow 返回黑图」，
   桌宠若停在微信右半屏正上方会干扰红圈检测。缓解：默认吸附避开右半屏 + 点击穿透；
   开工前真机验证「部分遮挡 vs 完全遮挡」的实际边界，确定避让规则。
2. 动画 CPU：帧率控制在 ~15fps，窗口隐藏/暂停态停帧，不叠加破坏 0.5s 轮询的 CPU 预算。
3. DPI：per-monitor aware 下桌宠缩放与多显示器定位需真机校验。
4. 生命周期：主窗口 hide ≠ 退出，桌宠常驻；退出只走右键菜单/托盘，引擎停止与记忆
   flush 语义不变。
