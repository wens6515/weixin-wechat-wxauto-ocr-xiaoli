# v2.6.0 更新记录 ——「状态监视」

## 新增

- **状态监视（条件触发器）**：「如果一会儿福州大学旗山校区下雨了提醒我去拿快递」这类请求现在能办了——AI 联网搜索后选定一个固定网页，后台按间隔轮询，条件达成或到截止时间时把触发事件连同页面状况回递给 AI，由它结合创建时的对话按人设生成回复：
  - **本地判定零 API 成本**：创建时模型看过页面后提交判定关键词，轮询只做本地匹配。支持 present（页面出现关键词，如「有货」）与 absent（关键词消失，如「等雨停」）两种判定方向
  - **scope 切片防误触发**：页面混合当前与未来时段（天气预报页「今天暴雨…周六晴」是真机实测会误判的场景）时，模型必须圈出当前时段切片，只匹配切片内文字，未来预报绝不参与判定
  - **api 判定模式**：需要理解语义或比较数值的条件，每次抓取后调模型判定（走唯一 API 链路）
  - 轮询间隔下限 10 秒、默认 60 秒；截止时间固定（非倒计时，暂停不顺延），不填默认 7 天；页面连续失效自动终止并告知
  - 设置页「状态监视」开关（默认关——api 判定与触发回递会产生额外 API 调用，是否开启由用户决定）
- **定时 / 条件触发器统一火线**：定时到点、条件达成、到期未达成、页面失效，全部回递 API 生成角色内回复——不再有「【定时提醒】xxx」式固定文案闹钟
- **用量统计升级**：
  - **缓存命中可见**：透传缓存命中 / 未命中 / 推理 tokens（DeepSeek 与 OpenAI 两种口径归一），按模型明细新增命中率列——上一版消息布局缓存优化的实际效果直接可查
  - **平台余额**：用量页一键查询已配置平台的真实余额（DeepSeek 实测通过，Moonshot / SiliconFlow 已适配；不支持的平台明示「请到控制台查看」，查询失败保留上次说明，绝不伪造 ¥0）
  - **估算消费**：内置各平台官方现行价目（DeepSeek 高峰/空闲分时、硅基流动凌晨闲时自动按调用时刻落档），按天估算消费并明确标注「估算」；价目可在 config 的 `price_overrides` 按模型覆盖，无价目的模型只计 token 不猜钱
  - **平均回复耗时**：从识别到红圈到产出回复的端到端耗时（含媒体防抖等待），与单次 API 调用耗时分开统计
  - **近 7 天调用量折线图**：每模型一条彩色折线，悬停节点弹出当天各模型调用量（替代此前一页露不全的表格）

## 优化

- **联网搜索三链重排（搜狗 > 必应 > 百度）**：真机高频实测百度 302 跳图形验证码基本全灭、搜狗唯一定期稳定供给且对中文实体查询精准，升为主源
- **网页抓取跟随跳转桩**：搜狗 /link 重定向返回的是 `window.location.replace(...)` 的 JS 桩，此前 requests 不执行 JS 导致「页面没有可读正文」误判失败（真机事故：天气查询两次抓取全败、模型只能说不知道）——现在自动提取桩内跳转目标跟随再抓
- **必应 2026-07 新版布局解析兜底**：改版后部分结果块标题链接不再包裹 `<h2>`（参照 Tianshu-harness 同款适配），旧解析会整块漏掉
- **状态监视创建时自动解析真实网址**：模型常直接选搜索结果里的搜狗跳转链接（会过期、展示无意义），创建时自动换算成最终目标页再入库
- **展示型表格锁死编辑**：触发器 / 用量 / 任务表格不再可双击改单元格；触发器表列宽自适应，表头与轮询目标完整显示

## 移除

- `set_reminder` 的 content（提醒事项）参数：到点/达成只回递事件，回复措辞由模型结合历史自行生成，不再预写「闹钟文案」
- 定时到点的【定时提醒】固定文案直发路径

## 修复

- 搜狗 /link 跳转桩抓取全败（见优化第二条，真机日志定位：模型两轮搜索两次抓取均失败后放弃回答）
- 必应在改版布局下贡献 0 条结果

## 升级注意

- **状态监视默认关闭**，需要请在设置页「定时消息与状态监视」里打开
- 旧 `reminders.json` 自动兼容：旧定时条目按定时触发器处理，无需迁移
- 用量统计旧记录无缓存字段，命中率列显示「—」；「平均回复耗时」从本版起积累

## 已知边界

- 状态监视轮询的是创建时选定的固定网页：页面改版或失效会提前终止并告知（连续 10 次异常）；本地判定依赖创建时按页面措辞给出的关键词，页面措辞大改可能拖到截止（到期会回递告知「没等到」）
- 百度高频访问仍会触发验证码（自动降级，由搜狗/必应补位）；海外渲染类服务（如 r.jina.ai）国内不可达，极端 JS 单页应用仍可能抓不到正文
- 抓取式搜索无 SLA：搜索引擎改版会导致解析失效（多源互为冗余 + 模型换措辞重搜兜底）
