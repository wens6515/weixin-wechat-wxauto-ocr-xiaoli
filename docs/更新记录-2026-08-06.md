## 正确性修复

1. **纯文字任务不带附件**（d1c7dc8）：文本消息触发任务时不再投递接收目录"最新"文件——此前用户没发文件也会把无关旧文件投给 agent 造成误判。附件只由文件消息路径投递（`_process_file_with_task` / `_process_file_with_instruction`）。删除死代码 `_latest_received_file`。
2. **初始化 KeyError 'vision_prompt'**（054176f）：config_store 补 AI_DEFAULTS 默认（与 wechat_bot 对齐）、WeChatBot 裸索引键改 get 兜底、活跃卡缺失回退模板投影。
3. **has_active_tasks 待回传任务被跳过**（ac3af7d）：有 result.json 未归档的任务此前被 `continue` 跳过（不算活跃），成果未发回微信前消息监听就恢复了——与注释意图/自检断言矛盾。已改为待回传即活跃，归档进 `sent/` 后才恢复监听（回传重试有稳定窗口）。
4. **GUI 与 CLI 双开互斥**（ac3af7d）：统一互斥体名 `XiaoLi_SingleInstance`——此前两个入口互不排斥，双开会同时抢微信窗口/发消息。
5. **微信连接重试可停止/限次**（ac3af7d）：`_connect_wx` 支持 stop_event 中断 + 重试上限（GUI 传 30 次 ≈ 5 分钟，超限抛异常 → 引擎 error 状态可重新初始化）；CLI 模式保留无限重试。
6. **去重集合限界**（ac3af7d）：`recent_msg_ids`（内存 5000 条上限，deque 丢最旧）与 `processed_ids.json`（10000 条上限）不再无限膨胀。
7. **gitignore 行尾注释污染**（8570074）：gitignore 无行尾注释语法，`bot.log.*   # 注释` 整行被当模式导致轮转文件不被忽略——注释移到独立行。

## 架构重构

1. **Controller 命令注册表**（dd56466）：删除 TianshuController 对 `_listen` 的 130 行复制，改为继承基类命令表 + 扩展 2 个命令（tianshu-window / task-status）。命令列表：`pause/resume/model/vision-model/chat-temp/chat-top-p/vision-temp/clear/del/memory/status/quit/help` + 任务桥扩展。
2. **统一配置加载**（dd56466）：CLI 的 `load_merged_config` 委托 `config_store.load_config_store`——GUI/CLI 同一事实源（迁移/投影/角色卡/多 provider），消除两套默认值并存。**CLI 默认 tasks_dir 从 `D:\工作间\wxauto` 变为便携默认（程序目录旁 `wxauto`）**。
3. **文件定位方法去重**（dd56466）：`_find_user_file`（含成果排除逻辑）上提父类 WeChatBot，AgentBot 删除 3 个重复方法。
4. **memory 节流写盘 + quit 优雅退出**（dd56466）：`_add_history` 节流（≤1s 合并写，脏标记 + flush）；quit 从 `os._exit(0)` 硬退改为 stop_event → bot.run 优雅退出（flush 记忆后退出，延迟约 2s）。
5. **CLI 切模型持久化**（dd56466）：`model xxx` / `vision-model xxx` 写回 config.json + 活跃角色卡（此前重启丢失）。
6. **scan_task_status 公共函数**（5c21b44）：CLI `task-status` 与 GUI 任务页共用任务扫描逻辑（此前各扫一遍，逻辑漂移）。

## 性能优化

1. **图片发送前压缩**（716da91）：截图最长边 >2048 等比缩放 + JPEG q=88（PIL，失败兜底 PNG）——4K 截屏 base64 直发会撑爆视觉 API 体积上限。
2. **token 估算中英加权**（716da91）：CJK 0.8 token/字、ASCII 0.3、其余 0.6（原 1 字符 = 1 token 对英文高估 4 倍，英文上下文利用率提升约 3 倍，仍偏保守）。
3. **模型端点拼接 rsplit**（716da91）：`models_endpoint()` 只替换最后一处 `/chat/completions`（`str.replace` 对含重复子串的自定义端点会拼错），fetch_models 与 UI 测试连接共用。

## 体验与安全

1. **API Key 落盘 DPAPI 加密**（5c21b44）：内存明文 / 落盘密文（`dpapi:` 前缀），旧明文 config 兼容迁移；换用户/换机解不开降级空 key 提示重填。config.json 不再含明文 key。
2. **日志轮转**（5c21b44）：RotatingFileHandler 2MB×2，不再每次启动清空 bot.log（可追溯）；`CONFIG = load_config()` 延迟到 `__main__`（import 零副作用，GUI/测试不受影响）。
3. **群聊判定集中**（ac3af7d）：`is_group_chat()` 单一判定点（wxauto4 SessionElement 是 .pyd 编译模块，未暴露群聊标志，维持名称启发式——群名不含"群"字会漏判，属已知局限）。
4. **群聊空内容文案对齐**（5c21b44）：`@小漓` 后空内容从 "Hello" 改为 "你好呀～"（与基类一致）。
